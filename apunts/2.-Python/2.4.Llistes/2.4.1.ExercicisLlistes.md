# Exercicis amb llistes

## Exercici 1 — Mostrar una llista

Donada la llista:

```python
numeros = [3, 6, 9, 12]
```

Mostra tots els elements per pantalla utilitzant un bucle `for`.

---

## Exercici 2 — Comptar elements

Donada la llista:

```python
numeros = [5, 0, 3, 0, 8]
```

Compta quants elements té la llista i mostra el resultat.

---

## Exercici 3 — Comptar zeros

Donada la llista:

```python
numeros = [2, 0, 4, 0, 0, 7]
```

Compta quants zeros hi ha dins de la llista.

---

## Exercici 4 — Suma dels elements

Donada la llista:

```python
numeros = [1, 4, 6, 3]
```

Calcula la suma de tots els elements de la llista.

---

## Exercici 5 — Llista des de teclat

Crea una llista buida i demana **5 números** a l’usuari.
Guarda’ls dins de la llista i mostra-la completa al final.

---

## Exercici 6 — Comptar positius

Donada la llista:

```python
numeros = [-2, 5, 0, 3, -1, 4]
```

Compta quants números **positius** hi ha.

---

## Exercici 7 — Buscar un valor

Donada la llista:

```python
numeros = [4, 8, 15, 16, 23, 42]
```

Demana un número a l’usuari i indica si està o no dins de la llista.

---

## Exercici 8 — Major de la llista

Donada la llista:

```python
numeros = [7, 2, 9, 4, 1]
```

Troba el **número més gran** de la llista sense utilitzar `max()`.

---

## Exercici 9 — Mitjana de la llista

Donada la llista:

```python
notes = [6, 8, 5, 9, 7]
```

Calcula i mostra la **mitjana** de les notes.

---

## Exercici 10 — Separar parells i senars

Donada la llista:

```python
numeros = [1, 4, 7, 8, 10, 3]
```

Crea dues llistes noves:

* una amb els números **parells**
* una amb els números **senars**

Mostra les dues llistes al final.

---

## Exercici 11 — Llista fins a parar

Demana números a l’usuari i guarda’ls en una llista.

* El programa ha d’acabar quan l’usuari introduïx **-1**
* El **-1 no s’ha de guardar**
* Mostra la llista final

---

## Exercici 12 — Comptador amb llista

Demana **10 números** a l’usuari.

* Guarda’ls en una llista
* Mostra:

  * quants són positius
  * quants són negatius
  * quants són zeros

---

## Exercici 13 — Taula de multiplicar amb llista

Demana un número `N`.

* Guarda dins d’una llista la seua taula de multiplicar del 1 al 10
* Mostra la llista completa

---

## Exercici 14 — Invertir una llista

Donada la llista:

```python
numeros = [1, 2, 3, 4, 5]
```

## Exercici 15 — Cas pràctic amb llistes

Crea un programa que:

* Demane **5 notes** a l’usuari
* Les guarde en una llista
* Mostre:

  * totes les notes
  * la nota més alta
