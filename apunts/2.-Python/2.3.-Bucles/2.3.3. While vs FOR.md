# 4. Transformacions entre `while` i `for` (ús bàsic)

En este punt del curs, treballem **només bucles que compten repeticions**.
No usem llistes ni col·leccions, únicament números i `range()`.

---

## 4.1 Cas típic: comptar cap avant

### Amb `while`

```python
i = 1

while i <= 5:
    print(i)
    i = i + 1
```

Este bucle té:

* inicialització (`i = 1`)
* condició (`i <= 5`)
* actualització (`i = i + 1`)

---

### Transformació a `for`

```python
for i in range(1, 6):
    print(i)
```

Què ha passat?

* `range(1, 6)` conté:

  * la inicialització
  * la condició
  * l’increment
* el `for` ho controla tot

---

## 4.2 Comptar des de 0

### Amb `while`

```python
i = 0

while i < 3:
    print("Hola")
    i = i + 1
```

---

### Amb `for`

```python
for i in range(3):
    print("Hola")
```

Transformació directa:

* `i = 0` → inici del `range`
* `i < 3` → límit del `range`
* `i = i + 1` → increment automàtic

---

## 4.3 Comptar cap arrere

### Amb `while`

```python
i = 5

while i > 0:
    print(i)
    i = i - 1
```

---

### Amb `for`

```python
for i in range(5, 0, -1):
    print(i)
```

Ací apareix una idea nova:

* el **pas negatiu** (`-1`)
* el `for` també pot comptar cap arrere

---

## 4.4 De `for` a `while` (camí invers)

### Amb `for`

```python
for i in range(4):
    print(i)
```

---

### Transformació a `while`

```python
i = 0

while i < 4:
    print(i)
    i = i + 1
```

Recordatori important:

> Quan passem de `for` a `while`, **hem d’escriure a mà tot el que el `for` feia sol**.

---

## 4.5 Exemple on `while` i `for` fan exactament el mateix

### Versió amb `for`

```python
for i in range(1, 4):
    print(i * 2)
```

---

### Versió amb `while`

```python
i = 1

while i < 4:
    print(i * 2)
    i = i + 1
```

Resultat en tots dos casos:

* es mostren els mateixos valors
* el comportament és idèntic

---

## 4.6 Quan **sí** podem transformar

Podem passar de `while` a `for` quan:

* hi ha un comptador numèric
* hi ha una condició clara amb `<`, `<=`, `>` o `>=`
* el comptador puja o baixa sempre igual

---

## 4.7 Quan **no** hem de transformar

No hem de passar a `for` quan:

* no sabem quantes repeticions hi haurà
* depenem d’una entrada d’usuari
* la condició canvia de manera irregular

Exemple correcte amb `while`:

```python
numero = int(input("Introdueix un número positiu: "))

while numero <= 0:
    numero = int(input("Error. Torna a introduir-lo: "))
```

---

## En resum

Hem de quedar-nos amb esta idea clau:

* `for` és ideal per a **comptar repeticions**
* `while` és millor per a **condicions obertes**
* molts `while` bàsics es poden simplificar amb `for`
* entendre la transformació ajuda a evitar errors
