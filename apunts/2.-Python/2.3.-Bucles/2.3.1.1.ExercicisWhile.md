# ERRORS AMB BUCLES WHILE



## Exercici 1

```python
num = 1

while num <= 5:
    print(num)
```

<details>
<summary>Solució</summary>
     
**Error:** bucle infinit.
    

**Explicació:**
La variable `num` no s’actualitza dins del bucle. Com que sempre val 1, la condició `num <= 5` sempre és certa i el bucle no acaba mai.

    
```python
num = 1

while num <= 5:
    print(num)
    num = num + 1
```
    
</details>

## Exercici 2

```python
num = 10

while num < 1:
    print(num)
    num = num - 1
```

<details>
<summary>Solució</summary>

**Error:** condició incorrecta.

**Explicació:**
`num` val 10 i la condició `num < 1` és falsa des del principi, per tant el bucle no s’executa ni una vegada.

```python
num = 10

while num >= 1:
    print(num)
    num = num - 1
```

</details>

## Exercici 3

```python
num = 1

while num <= 10:
    print(num)
    num = num - 1
```

<details>
<summary>Solució</summary>

**Error:** actualització incorrecta del comptador.

**Explicació:**
El bucle hauria d’avançar cap a 10, però `num` disminuïx. Això fa que la condició `num <= 10` siga sempre certa i el bucle siga infinit.

```python
num = 1

while num <= 10:
    print(num)
    num = num + 1
```

</details>

## Exercici 4

```python
while contador < 5:
    print(contador)
    contador = contador + 1
```

<details>
<summary>Solució</summary>

**Error:** variable no inicialitzada.

**Explicació:**
La variable `contador` s’utilitza abans de donar-li cap valor, cosa que provoca un error en executar el programa.

```python
contador = 0

while contador < 5:
    print(contador)
    contador = contador + 1
```

</details>

## Exercici 5

```python
num = 1

while num <= 5:
print(num)
num = num + 1
```

<details>
<summary>Solució</summary>

**Error:** error d’indentació.

**Explicació:**
El codi dins del `while` ha d’estar indentat. Sense indentació, Python no sap quin codi forma part del bucle.

```python
num = 1

while num <= 5:
    print(num)
    num = num + 1
```

</details>

## Exercici 6

```python
edat = int(input("Edat: "))

while edat >= 18:
    print("Major d'edat")
```

<details>
<summary>Solució</summary>

**Error:** ús incorrecte de `while`.

**Explicació:**
La condició no canvia dins del bucle. Si l’edat és major o igual que 18, el missatge es mostrarà infinitament. En este cas cal usar un `if`, no un `while`.

```python
edat = int(input("Edat: "))

if edat >= 18:
    print("Major d'edat")
else:
    print("Menor d'edat")
```

</details>

## Exercici 7

```python
num = int(input("Introdueix un número positiu: "))

while num < 0:
    print("Número incorrecte")
```

<details>
<summary>Solució</summary>

**Error:** el valor no s’actualitza dins del bucle.

**Explicació:**
Si `num` és negatiu, entra al bucle, però com no es torna a demanar un altre número, la condició no canvia i el bucle no pot acabar.

```python
num = int(input("Introdueix un número positiu: "))

while num < 0:
    print("Número incorrecte")
    num = int(input("Introdueix un número positiu: "))

print("Número correcte:", num)
```

</details>

## Exercici 8

```python
i = 1
suma = 0

while i <= 5:
    suma = suma + i
    i = i + 2

print("Suma:", suma)
```

<details>
<summary>Solució</summary>

**Error:** actualització incorrecta del comptador.

**Explicació:**
Amb `i = i + 2`, el bucle només suma alguns valors (1, 3, 5). Si es vol sumar tots els números de l’1 al 5, el comptador ha d’augmentar d’1 en 1.

```python
i = 1
suma = 0

while i <= 5:
    suma = suma + i
    i = i + 1

print("Suma:", suma)
```

</details>

## Exercici 9

```python
num = int(input("Introdueix un número (0 per acabar): "))

while num >= 0:
    print("Has escrit:", num)
    num = int(input("Introdueix un número (0 per acabar): "))
```

<details>
<summary>Solució</summary>

**Error:** condició de parada incorrecta.

**Explicació:**
Quan `num` és 0, la condició `num >= 0` continua sent certa. Si 0 ha de finalitzar el bucle, la condició ha de ser diferent de 0.

```python
num = int(input("Introdueix un número (0 per acabar): "))

while num != 0:
    print("Has escrit:", num)
    num = int(input("Introdueix un número (0 per acabar): "))
```

</details>

## Exercici 10

```python
opcio = 0

while opcio != 3:
    print("1. Saludar")
    print("2. Mostrar missatge")
    print("3. Eixir")

    if opcio == 1:
        print("Hola")
    elif opcio == 2:
        print("Missatge")
```

<details>
<summary>Solució</summary>

**Error:** la variable `opcio` no s’actualitza.

**Explicació:**
`opcio` mai canvia perquè no es llig cap valor de l’usuari. Això provoca un bucle infinit i el menú no permet interactuar.

```python
opcio = 0

while opcio != 3:
    print("1. Saludar")
    print("2. Mostrar missatge")
    print("3. Eixir")

    opcio = int(input("Tria una opció: "))

    if opcio == 1:
        print("Hola")
    elif opcio == 2:
        print("Missatge")
    elif opcio == 3:
        print("Eixint del programa")
    else:
        print("Opció no vàlida")
```

</details>
