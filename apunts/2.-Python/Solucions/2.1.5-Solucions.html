EXERCICI 1 — Calculadora bàsica amb operadors aritmètics

En este exercici construirem una calculadora senzilla utilitzant els operadors aritmètics bàsics de Python. El programa llegirà dos nombres reals introduïts per l’usuari i mostrarà el resultat de totes les operacions següents:

  • suma
  • resta
  • multiplicació
  • divisió
  • potència
  • mòdul (residu)
  • mitjana

Suposa que el segon nombre és diferent de zero; no cal comprovar-ho amb codi.

Eixida esperada (exemple)

Introdueix el primer número: 10
Introdueix el segon número: 3

Els resultats de les operacions són:

La suma és: 13.0
La resta és: 7.0
El producte és: 30.0
La divisió dona: 3.3333333333333335
La potència resulta en: 1000.0
El residu (mòdul) és: 1.0
La mitjana dels dos valors és: 6.5
Mostrar la solució comentada
# float permet llegir nombres amb decimals.
a = float(input("Introdueix el primer número: "))
b = float(input("Introdueix el segon número: "))
# L’enunciat suposa que b és diferent de zero.
print("Els resultats de les operacions són:")
print(f"La suma és: {a + b}")
print(f"La resta és: {a - b}")
print(f"El producte és: {a * b}")
print(f"La divisió dona: {a / b}")
print(f"La potència resulta en: {a ** b}")
print(f"El residu (mòdul) és: {a % b}")
# Els parèntesis fan que primer se sumen els dos valors.
print(f"La mitjana dels dos valors és: {(a + b) / 2}")

Crea un programa que demane els peus i les polzades addicionals d’una mesura i mostre la longitud total en centímetres.

Utilitza estes equivalències:

  • 1 polzada equival a 2.54 centímetres.
  • 1 peu equival a 12 polzades.

Eixida esperada (exemple)

Introdueix els peus: 4
Introdueix les polzades addicionals: 9

Mostrar la solució comentada

EXERCICI 4 — Descompondre una duració

Per separar una quantitat de segons en minuts i segons, podem utilitzar divisió entera (//) i residu (%):

s = 1234
minuts = s // 60
segons_restants = s % 60
print(f"{s} segons són {minuts} minuts i {segons_restants} segons")

Este exemple mostra 1234 segons són 20 minuts i 34 segons.

A partir d’este model, crea un programa que demane una quantitat de segons enters no negatius i la descomponga en hores, minuts i segons. Suposa que l’entrada és correcta; no cal validar-la.

Recorda que una hora té 3600 segons i un minut té 60 segons.

Pista: separar les parts del temps

Calcula primer les hores completes. Amb els segons que sobren després de llevar les hores, calcula els minuts complets. Finalment, calcula els segons que sobren després de llevar els minuts.

Eixida esperada (exemple)

Escriu una quantitat de segons: 12345
12345 segons són 3 hores, 25 minuts i 45 segons
Mostrar la solució comentada
# La duració és un nombre enter no negatiu, segons l’enunciat.
segons = int(input("Escriu una quantitat de segons: "))
# // calcula les hores completes i % conserva el que sobra.
hores = segons // 3600
resta = segons % 3600
# Descomponem la resta en minuts complets i segons.
minuts = resta // 60
segons_restants = resta % 60
print(f"{segons} segons són {hores} hores, {minuts} minuts i {segons_restants} segons")

EXERCICI 5 — Índex de Massa Corporal (IMC)

Anem a calcular l’Índex de Massa Corporal (IMC) d’una persona a partir de dos dades que proporcionarà l’usuari: el pes (en quilograms) i l’altura (en metres). El programa aplicarà la fórmula oficial:

IMC = pes / (altura²)

Suposa que l’altura introduïda és positiva; no cal comprovar-ho amb codi.

El resultat s’ha de mostrar amb un decimal, utilitzant formatació adequada.

Eixida esperada (exemple)

Quant peses? 78
Quant mesures en metres? 1.73
Segons les dades facilitades, el teu IMC és 26.1
Mostrar la solució comentada
pes = float(input("Quant peses? "))
altura = float(input("Quant mesures en metres? "))
# ** 2 eleva l’altura al quadrat. Suposem una altura positiva.
imc = pes / (altura ** 2)
# El format només arrodonix la presentació, no la variable.
print(f"Segons les dades facilitades, el teu IMC és {imc:.1f}")

Parella Primera expressió Segona expressió
1 17 / 5 17 // 5
2 17 // 5 17 % 5
3 2 + 3 * 4 (2 + 3) * 4
4 2 * 3 ** 2 (2 * 3) ** 2

# Parella 1: / dona el quocient decimal; // dona el quocient enter.

EXERCICI 9 — Gestió completa d’un viatge

En este exercici simularem els càlculs bàsics necessaris per planificar un viatge senzill.

El programa haurà de llegir, en este ordre:

  • la distància total del viatge (en quilòmetres),
  • el consum del vehicle (litres cada 100 km),
  • el preu del litre de combustible,
  • la duració del viatge en segons.

A partir d’estes dades, el programa calcularà i mostrarà:

  1. Els litres totals consumits.
  2. El cost total del combustible.
  3. El temps del viatge expressat en hores, minuts i segons.

Decideix les expressions necessàries i l’ordre dels càlculs a partir de les dades i les seues unitats.

Tots els resultats s’han de mostrar amb missatges clars.

Pista: relacionar distància, consum i cost

El consum indica els litres necessaris per recórrer 100 km. Calcula quants trams de 100 km té el viatge i relaciona’ls amb el consum. Després utilitza el preu de cada litre per obtindre el cost. Per al temps, recupera el procediment de l’exercici 4.

Eixida esperada (exemple)

Introdueix la distància del viatge (km): 250
Introdueix el consum del vehicle (L/100 km): 6.5
Introdueix el preu del litre de combustible (€): 1.75
Introdueix la duració del viatge en segons: 14400

Litres consumits: 16.25
Cost total del combustible: 28.4375 €

Duració del viatge:
4 hores, 0 minuts i 0 segons
Mostrar la solució comentada
distancia = float(input("Introdueix la distància del viatge (km): "))
consum = float(input("Introdueix el consum del vehicle (L/100 km): "))
preu_litre = float(input("Introdueix el preu del litre de combustible (€): "))
segons = int(input("Introdueix la duració del viatge en segons: "))
# El consum es dona per cada 100 km: ajustem-lo a la distància.

# Els litres consumits determinen el cost total.
cost = litres * preu_litre
# Separem hores completes, minuts i segons restants.
hores = segons // 3600

segons_restants = segons % 60
print(f"Litres consumits: {litres}")
print(f"Cost total del combustible: {cost} €")
print("Duració del viatge:")
print(f"{hores} hores, {minuts} minuts i {segons_restants} segons")
