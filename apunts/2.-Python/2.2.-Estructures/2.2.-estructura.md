# 1 Introducció a les condicions en Python

En la introducció a Python estem treballant estes **estructures condicionals**:

**1. Condicional simple: `if`**

Executa un bloc només quan la condició és certa.

```python
if condicio:
    instruccions
```

**2. Condicional amb dues alternatives: `if/else`**

Executa un bloc si la condició és certa i l’altre si és falsa.

```python
if condicio:
    instruccions_si_es_certa
else:
    instruccions_si_es_falsa
```

**3. Condicional amb diverses alternatives: `if/elif/else`**

Comprova les condicions en ordre i executa el primer bloc que correspon. Si cap es complix, executa l’`else`.

```python
if condicio_1:
    instruccions_del_primer_cas
elif condicio_2:
    instruccions_del_segon_cas
else:
    instruccions_dels_altres_casos
```

**4. Condicionals anidats**

Una decisió està dins d’una altra. La condició interior només es comprova si s’entra en el bloc exterior.

```python
if condicio_1:
    if condicio_2:
        instruccions
    else:
        altres_instruccions
else:
    instruccions_del_cas_exterior_fals
```

**5. Diversos `if` independents**

Cada condició es comprova per separat. Poden executar-se diversos blocs.

```python
if condicio_1:
    primera_accio

if condicio_2:
    segona_accio
```

En totes estes estructures podem utilitzar **condicions simples o compostes**:

```python
if edat >= 18:                  # Una comparació
    print("Major d'edat")

if edat >= 18 and soci:         # Condició composta
    print("Accés amb descompte")

if vip or autoritzacio:         # Alguna de les dues
    print("Accés autoritzat")

if not bloquejat:               # Negació
    print("Usuari habilitat")
```

**La indentació determina quines instruccions pertanyen a cada bloc.** Utilitzem quatre espais per nivell.
