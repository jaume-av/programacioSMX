## Exercici 1 — `if` amb condició simple

En este exercici treballarem el **condicional `if` més bàsic**.

Demana a l’usuari **un número enter**.
Comprova si el número és **major que 0**.
Si la condició és certa, mostra el missatge:

```
El número és positiu
```

Si no es compleix la condició, **no mostres cap missatge**.

---

## Exercici 2 — `if` amb igualtat

En este exercici practicarem una **comparació d’igualtat** dins d’un `if`.

Demana a l’usuari **un número enter**.
Comprova si el número és **exactament igual a 10**.
Si la condició és `True`, mostra el missatge:

```
El número és 10
```

---

## Exercici 3 — `if` amb rang (condició composta amb `and`)

En este exercici utilitzarem una **condició composta**.

Demana a l’usuari **la seua edat**.
Comprova si l’edat està **entre 12 i 17**, ambdós inclosos.
Si la condició es compleix, mostra el missatge:

```
Ets adolescent
```

---

## Exercici 4 — `if` amb `or`

En este exercici combinarem condicions amb l’operador `or`.

Demana a l’usuari:

* si és **VIP** (`True` o `False`),
* si és **soci** (`True` o `False`).

Comprova si l’usuari és **VIP o soci**.
Si la condició és certa, mostra el missatge:

```
Accés especial concedit
```

---

## Exercici 5 — `if` amb `not`

En este exercici utilitzarem l’operador `not`.

Demana a l’usuari si és **repetidor** (`True` o `False`).
Comprova si **no és repetidor**.
Si la condició es compleix, mostra el missatge:

```
Pot passar de curs
```

---

## Exercici 6 — `if` amb condició composta i parèntesis

En este exercici combinarem **diverses condicions** utilitzant `and`, `or` i parèntesis.

Demana a l’usuari:

* la seua **edat**,
* si és **VIP** (`True` o `False`),
* si és **soci** (`True` o `False`).

Comprova si:

* té **18 anys o més i és soci**,
* **o** és VIP.

Si la condició es compleix, mostra el missatge:

```
Pot entrar
```
