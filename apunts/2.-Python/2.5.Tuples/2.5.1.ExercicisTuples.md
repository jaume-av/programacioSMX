# Exercicis  Tuples

---

### Exercici 1 — Accés a elements

Crea una tuple amb els números:

```
8, 16, 24, 32
```

Mostra per pantalla:

* El segon element
* El penúltim element

---

### Exercici 2 — Recórrer i mostrar

Crea una tuple amb els mesos d’estiu:

```
"juny", "juliol", "agost"
```

Recorre la tuple amb un bucle `for` i mostra cada mes en una línia diferent.

---

### Exercici 3 — Suma i comptador

Crea una tuple amb 7 números enters.

Després:

* Mostra quants elements té.
* Calcula la suma total.
* Indica quants números són majors que 10.

(No pots modificar la tuple.)

---

### Exercici 4 — Coordenades i càlcul

Crea una tuple amb tres valors que representen:

```
(amplada, altura, profunditat)
```

Desempaqueta la tuple en tres variables i calcula:

* El producte dels tres valors.
* Mostra cada valor per separat.
* Mostra el resultat del producte.

---

### Exercici 5 — Dades des de teclat i anàlisi

Demana a l’usuari 5 números.

* Guarda’ls primer en una llista.
* Converteix la llista en una tuple.
* Mostra la tuple final.
* Recorre-la i indica:

  * Quin és el número més gran.
  * Quin és el número més menut.
  * Quants números són parells.

(No utilitzes funcions com `max()`, `min()` o `sum()`.)
