# Exercicis de Tuples

---

### Exercici 1

Crea una tuple amb els nombres:

```
5, 10, 15, 20
```

Mostra per pantalla:

* El primer element
* L’últim element

---

### Exercici 2

Crea una tuple amb els dies de la setmana laborables:

```
"dilluns", "dimarts", "dimecres", "dijous", "divendres"
```

Recorre la tuple amb un bucle `for` i mostra cada dia per pantalla.

---

### Exercici 3

Crea una tuple amb 6 números.

Després:

* Mostra quants elements té.
* Mostra la suma de tots els seus valors.

(No pots modificar la tuple.)

---

### Exercici 4

Crea una tuple que represente unes coordenades:

```
(25, 40)
```

Desempaqueta la tuple en dues variables anomenades `x` i `y` i mostra-les per pantalla amb este format:

```
Coordenada X: ...
Coordenada Y: ...
```

---

### Exercici 5

Demana a l’usuari 4 números per teclat.

* Guarda’ls primer en una llista.
* Després converteix la llista en una tuple.
* Mostra la tuple final.
* Indica quin és el número més gran recorreguent-la amb un bucle.

(No utilitzes funcions avançades com `max()`.)
