# Exercicis d'Operadors en Python

# **EXERCICI 1 — Analitza un perfil d’usuari**

### **Enunciat**

Tens les següents variables definides:

```python
nom = "Laura"
edat = 20
altura = 1.62
majoria_edad = 18
```

Escriu un programa que:

1. Mostre una frase concatenant textos i variables.
2. Calcule i mostre:

   * la diferència entre l’edat i la majoria d’edat
   * l’alçada multiplicada per 100
3. Compare si Laura és major d’edat.
4. Compare si la seua estatura és major que 1.70.

**Eixida esperada:**

```
Laura té 20 anys i fa 1.62 metres.
Diferència amb majoria d'edat: 2
Alçada en centímetres: 162.0
És major d'edat? True
És més alta que 1.70? False
```

# **EXERCICI 2 — Magatzem de productes**

### **Enunciat**

Suposa que tens un magatzem amb:

```python
preu_unitat = 12.5
stock_actual = 48
stock_minim = 30
nom_producte = "USB 32GB"
```

Fes que el programa:

1. Mostre el nom del producte i el seu preu unitat.
2. Calcule i mostre el valor total del stock (preu × unitats).
3. Comprove:

   * si el stock és inferior al mínim
   * si el valor total del magatzem és major que 500 €
4. Mostre totes les frases de manera clara utilitzant `f-strings`.

**Eixida esperada:**

```
Producte: USB 32GB, preu unitat: 12.5€
Valor total en magatzem: 600.0€
Stock per davall del mínim? False
Valor total superior a 500€? True
```

# **EXERCICI 3 — Comparació de cadenes**

### **Enunciat**

Tens dos textos:

```python
a = "Python"
b = "python"
```

Programa que mostre:

1. La concatenació de les dues paraules separades per un espai.
2. Comprovacions:

   * si `a` i `b` són iguals
   * si `a` és menor alfabèticament que `b`
3. El resultat de convertir `b` en majúscules i comparar-lo amb `a`.

**Eixida esperada:**

```
Python python
Són iguals? False
"A" és menor que "b"? True
b en majúscules és igual a a? True
```

# **EXERCICI 4 — Taula de valors booleans**

### **Enunciat**

Crea tres variables booleanes:

```python
x = True
y = False
z = True
```

Mostra:

1. Els resultats de:

   * x and y
   * x or y
   * not x
   * x and z
   * y or z
2. Presenta els resultats un per línia amb format clar.

**Eixida esperada:**

```
x and y = False
x or y = True
not x = False
x and z = True
y or z = True
```

# **EXERCICI 5 — Operacions diverses**

### **Enunciat**

Utilitza les següents variables:

```python
a = 15
b = 4
c = "Nota final"
```

El programa ha de:

1. Mostrar una frase combinant text i número utilitzant **f-strings**.
2. Calcular i mostrar:

   * la divisió decimal
   * la divisió entera
   * el residu
3. Convertir `a` a text i concatenar-lo amb `c`.

**Eixida esperada:**

```
El valor de a és 15
Divisió decimal: 3.75
Divisió entera: 3
Residu: 3
Nota final 15
```
