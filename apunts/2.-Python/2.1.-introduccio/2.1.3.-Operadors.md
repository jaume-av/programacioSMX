# **2.1.3 Operadors en Python**


Els operadors són símbols especials que realitzen operacions sobre valors i variables. 

En programació, els operadors es solen utilitzar per a realitzar càlculs, comparacions i operacions lògiques en els nostres programes.

Hi ha tres tipus principals d'operadors en Python:

* **Operadors aritmètics:** permeten fer càlculs com sumar, restar, multiplicar i dividir.
* **Operadors relacionals:** permeten fer comparacions com igualtat, desigualtat, major que i menor que. Estos operadors retornen valors booleans (**True o False**).
* **Operadors lògics:** permeten combinar condicions utilitzant **AND, OR i NOT**. Estos operadors també retornen valors booleans (**True o False**).


Estos operadors ens permetran crear programes que calculen, decideixen i comproven condicions.

---

## **1. Operadors aritmètics**

Els operadors aritmètics s'utilitzen per a realitzar operacions matemàtiques bàsiques. Python ofereix estes operacions:


| Operador | Significat     |
| -------- | -------------- |
| **+**    | Suma           |
| **-**    | Resta          |
| **\***   | Multiplicació  |
| **/**    | Divisió        |
| **//**   | Divisió entera |
| **%**    | Mòdul (residu) |
| **       | Potència       |

Exemples:

```python
x = 10
y = 3

print(x + y)     # 13
print(x / y)     # 3.333...
print(x // y)    # 3
print(x % y)     # 1
print(x ** y)    # 1000
```

---

## **2. Operadors relacionals**

Comparen dos valors i tornen True o False:

| Operador | Significat    |
| -------- | ------------- |
| **==**   | Igual         |
| **!=**   | Diferent      |
| **<**    | Menor         |
| **<=**   | Menor o igual |
| **>**    | Major         |
| **>=**   | Major o igual |

Exemple:

```python
edat = 18
print(edat >= 18)  # True
print(edat < 21)   # True
print(edat == 20)  # False
print(edat != 15)  # True
```

---

## **3. Operadors lògics**

Ens permeten combinar condicions, es a dir, comparar múltiples expressions al mateix temps. açò és útil quan volem prendre decisions més complexes en els nostres programes.

| Operador | Significat                   |
| -------- | ---------------------------- |
| **and**  | Les dues condicions són True |
| **or**   | Almenys una condició és True |
| **not**  | Inverteix True/False         |

Exemples:

```python
print(3 > 2 and 5 > 1)   # True
print(3 > 4 or 2 > 1)    # True
print(not False)         # True
```

---

## **4. Errors habituals**

És important reconéixer alguns errors bàsics:

### IndentationError (espais incorrectes)

```python
if True:
print("hola")   # Incorrecte
```

Solució:

```python
if True:
    print("hola")
```

### NameError (variable no definida)

```python
print(x)   # x no existeix
```

### TypeError (sumar text i número)

```python
edat = int(input("Edat: "))
print("Tens " + edat + " anys")  # Error
```

Solució:

```python
print("Tens", edat, "anys")
```

# **2.1.4 Entrada i eixida en Python + Exercicis**

En esta unitat aprendrem a mostrar informació i a demanar dades a l’usuari. És la base per crear programes interactius.

---

## **1. Mostrar informació amb print**

Python permet mostrar textos, variables i expressions.

```python
print("Hola món")
nom = "Anna"
print("Hola", nom)
```

Podem canviar el separador:

```python
print(2, 4, 6, sep="-")  # 2-4-6
```

La manera recomanada per intercalar variables és utilitzar f-strings:

```python
nom = "Pau"
edat = 16
print(f"{nom} té {edat} anys")
```

---

## **2. Demanar informació a l’usuari**

La funció `input()` mostra un missatge i espera que l’usuari escriga alguna cosa.

Sempre retorna un text.

### Exemple bàsic

```python
nom = input("Com et dius? ")
print("Encantat,", nom)
```

### Exemple amb números

```python
a = int(input("Primer número: "))
b = int(input("Segon número: "))
print("La suma és:", a + b)
```

### Exemple amb decimals

```python
nota = float(input("Escriu la teua nota: "))
print("Has tret un", nota)
```
