# 2.1. Introducció a Python

## 1. Dels algoritmes als programes

Fins ara hem aprés a dissenyar algoritmes utilitzant pseudocodi i diagrames de flux. Hem treballat amb variables, operacions, condicionals i bucles per a resoldre problemes de manera ordenada.

Però hi ha una diferència important entre dissenyar un algoritme i executar-lo en un ordinador.

- Un algoritme és un conjunt d'instruccions ordenades per a resoldre un problema.
- El pseudocodi permet representar eixes instruccions d'una manera senzilla, sense dependre d'un llenguatge de programació concret.
- Un programa és la implementació d'un algoritme en un llenguatge de programació que l'ordinador pot executar.

Per tant, el següent pas serà transformar els algoritmes que ja sabem dissenyar en programes reals.

Per a aconseguir-ho, utilitzarem el llenguatge de programació Python.

## 2. Què és Python?

Python és un llenguatge de programació d'alt nivell i de propòsit general que permet desenvolupar programes informàtics de manera relativament senzilla.

Va ser creat per Guido van Rossum i publicat per primera vegada en 1991.

Una de les seues característiques principals és que utilitza una sintaxi clara i fàcil de llegir, cosa que el convertix en un llenguatge especialment adequat per a començar a programar.

### 2.1. Característiques de Python

Python presenta diversos avantatges:

- Sintaxi senzilla: les instruccions són relativament fàcils de llegir i escriure.
- Multiplataforma: podem utilitzar-lo en Linux, Windows i macOS.
- Gratuït i de codi obert: es pot utilitzar, estudiar i modificar lliurement, respectant la seua llicència.
- Interpretat: habitualment executem els programes mitjançant l'intèrpret de Python, sense haver de compilar-los manualment.
- Versàtil: permet crear aplicacions de molts tipus.
- Gran comunitat: disposa de nombroses biblioteques i recursos que faciliten el desenvolupament de programes.

## 4. Del pseudocodi a Python

Una de les idees més importants que hem de comprendre és que un mateix algoritme es pot representar de diferents maneres.

Podem expressar-lo amb un diagrama de flux, escriure'l en pseudocodi o implementar-lo en un llenguatge de programació com Python.

La lògica de l'algoritme és la mateixa. El que canvia és la manera d'escriure les instruccions.

### 4.1. Exemple: calcular el doble d'un número

Suposem que volem crear un programa que calcule el doble del número 5.

Primer representem l'algoritme en pseudocodi:

PSEUDOCODI

```
INICI
    numero ← 5
    doble ← numero * 2
    MOSTRAR doble
FI
```

Ara escrivim el mateix algoritme en Python:

```python
numero = 5
doble = numero * 2
print(doble)
```

Resultat en executar el programa:

```
10
```

### 4.2. Què ha canviat?

Compareu les instruccions dels dos llenguatges:

| Pseudocodi           | Python               | Funció                                     |
| -------------------- | -------------------- | ------------------------------------------ |
| `INICI` / `FI`       | No són necessaris    | Delimitar l'algoritme en pseudocodi.       |
| `numero ← 5`         | `numero = 5`         | Assignar un valor a una variable.          |
| `doble ← numero * 2` | `doble = numero * 2` | Realitzar un càlcul i guardar el resultat. |
| `MOSTRAR doble`      | `print(doble)`       | Mostrar el resultat per pantalla.          |

Com podem observar:

- Les variables continuen utilitzant-se per a guardar informació.
- Les operacions matemàtiques són pràcticament iguals.
- L'assignació es representa amb el símbol `=` en Python.
- La instrucció `MOSTRAR` se substituïx per `print()`.
- No necessitem escriure `INICI` ni `FI`.

La diferència principal és que Python té unes regles de sintaxi pròpies que hem d'aprendre i respectar.

### 4.3. Un altre exemple

Observa el següent algoritme:

Pseudocodi:

```
INICI
    preu ← 20
    quantitat ← 3
    total ← preu * quantitat
    MOSTRAR total
FI
```

Python:

```python
preu = 20
quantitat = 3
total = preu * quantitatprint(total)

```

Resultat:

```
60
```

En este exemple, els dos algoritmes realitzen exactament les mateixes operacions.

A mesura que avancem, aprendrem a traduir a Python altres estructures que ja coneixem, com els condicionals i els bucles.

## 7. Compilat vs Interpretat

Un llenguatge de programació pot ser compilat o interpretat. La principal diferència és la manera en què s'executen els programes. En el cas dels llenguatges compilats, com Java, C o C++, el codi font es tradueix a codi màquina abans d'executar-lo. En canvi, els llenguatges interpretats, com Python, s'executen directament línia per línia mitjançant un intèrpret.


- **Exemple Python:**
  
```python
numero = 7

if numero == 7:
  print("El número es exactamente 7")
else:
  print("El número no es 7")
``` 

- **Exemple Python:**

```java
public class Main {
    public static void main(String[] args) {
        int numero = 7;

        if (numero == 7) {
            System.out.println("El número es exactamente 7");
        } else {
            System.out.println("El número no es 7");
        }
    }
}
```
