# **2.1.4 Entrada i eixida en Python + Exercicis**

Per eixida i entrada ens referim a **mostrar informació** i a **demanar dades** a l’usuari.
Això ens permetrà crear programes interactius que responen segons el que escriga la persona que els utilitza.

---

## **1. Mostrar informació amb `print()`**

La funció `print()` mostra per pantalla qualsevol missatge, variable o resultat d’una operació.

### Exemple bàsic

```python
print("Hola món")
```

També podem mostrar variables:

```python
nom = "Anna"
print("Hola", nom)
```

En aquest cas, `print()` separa cada element amb un espai.

---

### **Canviar el separador entre els elements**

Podem utilitzar el paràmetre `sep` per definir quin caràcter volem que separen els elements:

```python
print(2, 4, 6, sep="-")   # Mostra: 2-4-6
print("a", "b", "c", sep=" | ")   # Mostra: a | b | c
```

---

### **Intercalar variables en un text: f-strings**

La forma més clara i recomanada d’incloure variables dins d’un text és utilitzar **f-strings**, és a dir, posar una *f* davant de les cometes i les variables entre `{}`.

```python
nom = "Pau"
edat = 16
print(f"{nom} té {edat} anys")
```

Això és molt més llegible que fer concatenacions o cridar múltiples arguments.

### Exemple amb operacions

```python
a = 5
b = 3
print(f"La suma de {a} i {b} és {a + b}")
```

### Exemple ben formatat

```python
preu = 12.5
print(f"El producte costa {preu:.2f} €")
```

`.2f` indica que volem 2 decimals.

---

## **2. Demanar informació amb `input()`**

La funció `input()` mostra un text i **espera** que l’usuari escriga alguna cosa i preme Enter.

Important:
**`input()` sempre retorna un text (string)**, encara que l’usuari escriga números.

---

### Exemple bàsic

```python
nom = input("Com et dius? ")
print("Encantat,", nom)
```

---

### **Per què cal convertir el resultat?**

Si volem operar amb números, primer hem de convertir el text:

```python
edat = int(input("Quants anys tens? "))
print("L'any que ve tindràs", edat + 1)
```

Sense la conversió amb `int()`, Python no permetria fer sumes.

---

### Exemple amb enters

```python
a = int(input("Primer número: "))
b = int(input("Segon número: "))
print("La suma és:", a + b)
```

---

### Exemple amb decimals

```python
nota = float(input("Escriu la teua nota: "))
print("Has tret un", nota)
```

---

### Exemple d'ús combinat

Demana dades i mostra-les amb un f-string:

```python
nom = input("Nom: ")
altura = float(input("Altura en metres: "))
print(f"{nom} fa {altura} metres d'altura")
```

---

## **Exemples més complets per a classe**

### **Calculadora simple**

```python
x = float(input("Número 1: "))
y = float(input("Número 2: "))

print(f"Suma: {x + y}")
print(f"Resta: {x - y}")
print(f"Multiplicació: {x * y}")
print(f"Divisió: {x / y}")
```

---

### **Missatge personalitzat**

```python
nom = input("Com et dius? ")
any_naixement = int(input("Any de naixement: "))

any_actual = 2025
edat = any_actual - any_naixement

print(f"Hola {nom}, tens {edat} anys.")
```

# **Errors habituals amb `print()` i `input()`**

Quan comencem a utilitzar `print()` i `input()`, és normal trobar alguns errors molt típics. A continuació tens una guia clara perquè els pugues identificar i corregir sense problema.

---

## **1. Error: Sumar un text i un número**

`input()` sempre retorna un **text**, encara que escrigues un número.
Si intentes sumar-lo directament amb un enter, apareix un TypeError.

### Incorrecte

```python
edat = input("Edat: ")
print("L'any que ve tindràs " + edat + 1)
```

**Error produït:**

```
TypeError: can only concatenate str (not "int") to str
```

### Solució

Convertir a enter **abans** de sumar:

```python
edat = int(input("Edat: "))
print("L'any que ve tindràs", edat + 1)
```

També funciona amb f-string:

```python
print(f"L'any que ve tindràs {edat + 1}")
```

---

## **2. Error: Oblidar parèntesis en `print` o `input`**

En Python 3, **print i input són funcions** i necessiten parèntesis.

### Incorrecte

```python
print "Hola"
nom = input "Nom: "
```

### Solució

```python
print("Hola")
nom = input("Nom: ")
```

---

## **3. Error: No convertir un número decimal**

Quan necessitem decimals, cal utilitzar `float()` i no `int()`.

### Incorrecte

```python
nota = int(input("Nota: "))   # Si introdueixes 7.5 peta
```

### Solució

```python
nota = float(input("Nota: "))
```

---

## **4. Error: Intentar fer operacions sense convertir**

Este error és molt comú quan es treballa amb cadenes que representen números.

### Incorrecte

```python
a = input("Número: ")
b = input("Número: ")
print(a * b)   # Error!
```

Python intenta multiplicar textos, cosa que no té sentit.

### Solució

```python
a = int(input("Número: "))
b = int(input("Número: "))
print(a * b)
```

---

## **5. Error: No deixar espai en el missatge d’input**

Això no és un error tècnic, però sí un error habitual de presentació.
Si no poses un espai al final, el text queda enganxat.

### Incorrecte

```python
nom = input("Com et dius?")
```

El cursor queda així:

```
Com et dius?A...
```

### Solució estètica

```python
nom = input("Com et dius? ")
```

---

## **6. Error: No utilitzar f-strings quan és necessari**

No és un error del llenguatge, però sí un **mal hàbit** habitual.

### Exemple millorable

```python
print("Hola", nom, "tens", edat, "anys")
```

### Millor amb f-string

```python
print(f"Hola {nom}, tens {edat} anys")
```

Més llegible, més curt i més modern.

---

## **7. Error amb `sep` i `end` per desconeixement**

A voltes l’alumnat pensa que `print()` sempre fa un salt de línia.
Açò no és cert: `end` ho controla.

### Exemple útil

```python
print("Hola", end=" ")
print("món")
```

Resultat:

```
Hola món
```

### Exemple amb `sep`

```python
print("A", "B", "C", sep=" | ")
```

Resultat:

```
A | B | C
```

---

## **8. Error: Escriure `int(input)` sense parèntesis**

Això no executa `input()`, només mostra informació de la funció.

### Incorrecte

```python
edat = int(input)
```

### Solució

```python
edat = int(input("Edat: "))
```

---

## **9. Error: Insistir en concatenar `+` en lloc d’usar comes**

Quan comencem, solem abusar de `+`.

### Incorrecte

```python
print("La suma és " + a + b)
```

Si `a` i `b` són números, error.

### Solucions correctes

```python
print("La suma és", a + b)
```

o

```python
print(f"La suma és {a + b}")
```

---

## **10. Error: Obrir i tancar cometes incorrectament**

Les cometes han d’anar sempre aparellades.

### Incorrecte

```python
print("Hola món')
```

### Correcte

```python
print("Hola món")
print('Hola món')
```

# En resum:



## **Entrada i eixida en Python**

| **Element**             | **Què fa?**                        | **Exemple**                      | **Resultat/Explicació**      |
| ----------------------- | ---------------------------------- | -------------------------------- | ---------------------------- |
| **`print()`**           | Mostra dades per pantalla          | `print("Hola")`                  | Escriu *Hola*                |
| **Mostrar variables**   | `print(a, b)` separa amb espais    | `print(2, 3)`                    | `2 3`                        |
| **Separador (`sep`)**   | Canvia el separador entre elements | `print(2, 4, 6, sep="-")`        | `2-4-6`                      |
| **Final (`end`)**       | Evita el salt de línia             | `print("Hola", end=" ")`         | No fa salt de línia          |
| **f-strings**           | Intercale variables dins d’un text | `print(f"{nom} té {edat} anys")` | Més clar i modern            |
| **`input()`**           | Demana informació a l’usuari       | `nom = input("Nom: ")`           | Guarda sempre **text**       |
| **Convertir a enter**   | Convertix text a número enter      | `edat = int(input("Edat: "))`    | Necessari per sumar/restar   |
| **Convertir a decimal** | Convertix text a número decimal    | `preu = float(input("Preu: "))`  | Per treballar amb decimals   |
| **Convertir a text**    | Convertix un valor a cadena        | `t = str(25)`                    | Útil per concatenar textos   |
| **Error habitual**      | No convertir abans d’operar        | `input()` retorna text           | Cal usar `int()` o `float()` |
| **Cometes**             | Poden ser simples o dobles         | `"Hola"` o `'Hola'`              | S’han de tancar bé           |
