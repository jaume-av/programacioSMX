## **EXERCICI 3 — Corregir un convertidor de temperatures**

Este programa ha de convertir una temperatura de **Celsius a Fahrenheit** i una altra de **Fahrenheit a Celsius**, però conté errors.

Les fórmules correctes són:

```
F = 1.8 · C + 32
C = (F − 32) / 1.8
```

```python
celsius = input("Introdueix una temperatura en ºC: ")
fahrenheit = 1.8 * celsius + 32
print(f"La temperatura transformada a ºF és: {fahrenheit} ºF")

fahrenheit = float(input("Introdueix una temperatura en ºF: "))
celsius = fahrenheit - 32 / 1.8
print(f"Convertint a graus Celsius obtenim: {celsius} ºC")
```

1. Abans d’executar-lo, identifica el problema de conversió de l’entrada i el problema de precedència.
2. Corregix-los i adapta les f-strings perquè els resultats tinguen **un decimal**.
3. Executa el programa amb les dades següents i explica breument cada canvi.

### **Eixida esperada**

```
Introdueix una temperatura en ºC: 36.5
La temperatura transformada a ºF és: 97.7 ºF

Introdueix una temperatura en ºF: 451
Convertint a graus Celsius obtenim: 232.8 ºC
```

## **EXERCICI 4 — Descompondre una duració**

Per separar una quantitat de segons en minuts i segons, podem utilitzar **divisió entera (`//`)** i **residu (`%`)**:

```python
s = 1234
minuts = s // 60
segons_restants = s % 60
print(f"{s} segons són {minuts} minuts i {segons_restants} segons")
```

Este exemple mostra `1234 segons són 20 minuts i 34 segons`.

A partir d’este model, crea un programa que demane una quantitat de **segons enters no negatius** i la descomponga en **hores, minuts i segons**. Suposa que l’entrada és correcta; no cal validar-la.

Recorda que una hora té 3600 segons i un minut té 60 segons.

<details markdown="1">
<summary>Pista: separar les parts del temps</summary>

Calcula primer les hores completes. Amb els segons que sobren després de llevar les hores, calcula els minuts complets. Finalment, calcula els segons que sobren després de llevar els minuts.

</details>

### **Eixida esperada (exemple)**

```
Escriu una quantitat de segons: 12345
12345 segons són 3 hores, 25 minuts i 45 segons
```

## **EXERCICI 6 — Predir, comprovar i explicar expressions**

Abans d’executar cap codi, escriu el resultat que esperes de cada expressió. Després comprova’l amb `print()` i explica les diferències dins de cada parella.

**Exemple resolt:** `2 + 3 * 4` dona `14`, perquè la multiplicació es calcula abans que la suma.

| Parella | Primera expressió | Segona expressió |
| --- | --- | --- |
| 1 | `17 / 5` | `17 // 5` |
| 2 | `17 // 5` | `17 % 5` |
| 3 | `2 + 3 * 4` | `(2 + 3) * 4` |
| 4 | `2 * 3 ** 2` | `(2 * 3) ** 2` |
| 5 | `20 - 8 / 2` | `(20 - 8) / 2` |

Si una predicció no coincideix amb l’execució, explica quin operador o quina regla de precedència havies interpretat incorrectament.
