# Exercicis de variables i tipus de dades en Python

En estos exercicis practicarem els conceptes treballats en la unitat: **variables, tipus de dades, assignacions, cadenes de text, conversions i intercanvi de valors**.

Treballarem també la lectura de codi, la predicció de resultats i la detecció d'errors.

## Instruccions generals

- Crea una carpeta anomenada `02_Variables` per a guardar els programes.
- Utilitza un fitxer `.py` diferent per a cada exercici.
- Escriu noms de variables descriptius i utilitza `snake_case`.
- Inclou comentaris quan siguen necessaris per a explicar el codi.
- Guarda i executa els programes amb VS Code.
- Comprova que els resultats són correctes.

>Nota: Els punts de raonament i reflexió contesta dins del fitxer `.py` com a comentaris, no en un fitxer separat. Usa les cometes triples `"""` per a blocs de comentari llargs.

## Exercici 1 — Variables i tipus de dades

**Objectiu:** crear variables de diferents tipus i comprovar els seus valors.

Crea un programa anomenat `tipus_dades.py`.

### Apartat A. Crear variables

Declara les següents variables amb els valors indicats:

| Variable | Valor |
|---|---|
| `nom` | "Maria" |
| `edat` | 17 |
| `altura` | 1.68 |
| `matriculat` | True |
| `codi_postal` | "12600" |

El programa ha de mostrar el valor de totes les variables.

### Apartat B. Identificar els tipus

Utilitza la funció `type()` per a mostrar el tipus de cadascuna de les variables.

Respon també:

1. De quin tipus és `edat`?
2. Quina diferència hi ha entre `edat` i `codi_postal`?
3. Per què `matriculat` no s'ha d'escriure entre cometes?
4. Quin tipus té `altura`?

### Apartat C. Modificar variables

Modifica el programa perquè:

- L'edat passe a ser 18.
- L'altura passe a ser 1.70.
- `matriculat` passe a ser `False`.

Mostra els nous valors i comprova si els tipus han canviat.

## Exercici 3 — Seguiment de variables i assignacions

**Objectiu:** comprendre com canvien els valors de les variables durant l'execució d'un programa.

### Apartat A. Predir els resultats

Observa el següent programa:

```python
a = 10
b = 4
c = 2

a = a + b
b = a - c
c = b + a
a = c - b

print(a, b, c)
```

**Abans d'executar el programa**, completa la taula indicant el valor de totes les variables després de cada instrucció.

| Instrucció | a | b | c |
|---|---|---|---|
| Valors inicials | 10 | 4 | 2 |
| `a = a + b` | | | |
| `b = a - c` | | | |
| `c = b + a` | | | |
| `a = c - b` | | | |

Després, crea el fitxer `seguiment_variables.py`, executa el programa i comprova els resultats.

### Apartat B. Modificar valors

Modifica únicament els valors inicials:

```python
a = 20
b = 5
c = 3
```

Sense executar-lo, torna a calcular els valors finals de les tres variables.

Després executa el programa per a comprovar-los.

### Apartat C. Raonament

Respon:

1. Quan executem `a = a + b`, què passa amb el valor anterior de `a`?
2. En la instrucció `b = a - c`, s'utilitza el valor inicial de `a` o el valor actualitzat?
3. Per què és important respectar l'ordre de les assignacions?

## Exercici 4 — Intercanvi de valors

**Objectiu:** comprendre les assignacions i aprendre a intercanviar el contingut de dues variables.

Crea un programa anomenat `intercanvi.py`.

### Apartat A. Detectar el problema

Observa el següent codi:

```python
a = 15
b = 30

a = b
b = a

print(a, b)
```

Abans d'executar-lo, respon:

1. Quins valors tindran `a` i `b` al final?
2. S'han intercanviat correctament?
3. Què ha passat amb el valor original de `a`?

Executa el programa i comprova les respostes.

### Apartat B. Variable auxiliar

Modifica el programa per a intercanviar correctament els valors de `a` i `b` utilitzant una **variable auxiliar**.

El programa ha de mostrar els valors abans i després de l'intercanvi.

Resultat esperat:

```text
Abans: 15 30
Després: 30 15
```

### Apartat C. Assignació múltiple

Realitza el mateix intercanvi, però esta vegada utilitzant la sintaxi pròpia de Python:

```python
a, b = b, a
```

### Apartat D. Comparació

Respon:

1. Quantes instruccions necessites per a intercanviar els valors amb una variable auxiliar?
2. Quantes instruccions necessites amb l'assignació múltiple?
3. Quin avantatge té l'assignació múltiple de Python?

## Exercici 6 — Detectar i corregir errors

**Objectiu:** identificar errors habituals relacionats amb variables, tipus de dades, conversions i assignacions.

En cada apartat:

1. Observa el codi sense executar-lo.
2. Indica si produirà un error o un resultat incorrecte.

4. Corregix el programa, si és necessari.
5. Executa'l per a comprovar la correcció.

Crea un fitxer anomenat `correccio_errors.py`.

Pots copiar i provar cada fragment per separat.

### Apartat A. Noms de variables

```python

```

### Apartat B. Concatenació

```python

```

Respon:

1. Este programa és correcte?
2. Quin resultat mostrarà?
3. Quin tipus té `numero` abans i després de la conversió?


### Apartat F. Assignacions
