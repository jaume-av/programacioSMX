# **Com començar amb Python i Visual Studio Code**

Visual Studio Code és un editor molt complet i lleuger que ens permet escriure codi Python de manera ràpida i còmoda. 

Hem de tindre en compte que, per a treballar amb Python, necessitem **dos elements**:

* **Python** instal·lat en l’ordinador.
* **VS Code** amb les extensions adequades.

(En Lliurex/Ububntu, Python ja ve instal·lat per defecte).

---

## **1. Instal·lar Python**

Abans d’obrir VS Code, necessitem tindre Python instal·lat.

1. Obre la web oficial:
   **[https://www.python.org/downloads](https://www.python.org/downloads)**
2. Prem **Download Python** (agafa la versió recomanada).
3. Quan s’òbriga l’instal·lador:

   * Activa **"Add Python to PATH"** (molt important).
   * Prem **Install Now**.

Una vegada acaba, Python ja està preparat.

Per comprovar-ho:

* Obri una terminal (CMD o PowerShell).
* Escriu:

```
python3 --version
```

Si mostra una versió (per exemple, 3.12), tot està bé.


>**IMPORTANT!** Error habitual durant la instal·lació:
“python no es reconeix com a ordre”

**Vol dir que no vas marcar “Add Python to PATH”.**

Tens dues solucions:

-**Solució** 1 (recomanada): reinstal·lar Python

Desinstal·la’l i instal·la’l de nou marcant “Add Python to PATH”.

-**Solució** 2: modificar PATH manualment
Només recomanable per a alumnat avançat. Indica que quasi sempre és millor reinstal·lar.




---

## **2. Instal·lar Visual Studio Code**

1. Ves a: **[https://code.visualstudio.com/](https://code.visualstudio.com/)**
2. Prem **Download**.
3. Instal·la’l amb les opcions per defecte.

Quan s’òbriga, ja el tenim llest per configurar.

---

## **3. Extensions necessàries per a Python**

VS Code funciona amb extensions. Les que necessitem són:

* **Python** (oficial de Microsoft) (**OBLIGATÒRIA**)
* **Pylance** (millor autocompletat i suggeriments) (**RECOMANADA**)
* **Python Debugger** (per executar i depurar) (**RECOMANADA**)

Per instal·lar-les:

1. A l'esquerra, obri la icona de **Extensions** (quadradet amb quatre blocs).
2. Busca “Python”.
3. Instal·la l’extensió oficial (té més de 50 milions de descàrregues).
4. Busca “Pylance” i instala’l.
5. Busca “Python Debugger” i instala’l.

Amb estes tres extensions ja podem programar perfectament.

---

## **4. Crear una carpeta per al projecte**

És recomanable treballar dins d’una carpeta.

1. Crea una carpeta nova al teu ordinador, per exemple:
   **projecte-python**
2. Obri VS Code.
3. Ves a **File → Open Folder**.
4. Tria la carpeta creada.

VS Code treballarà directament sobre esta carpeta.

---

## **5. Crear el primer fitxer Python**

1. En la barra lateral esquerra, fes clic a **New File**.
2. Dona-li un nom com **hola.py**
   (és molt important posar `.py`).

>Nota: L'extensió `.py` indica que és un fitxer de Python. Tots els fitxers de Python han de tindre esta extensió.

En este fitxer escriu:

```python
print("Hola món des de Python!")
```

Guarda el fitxer.

---

## **6. Executar el programa**

Hi ha diverses maneres d'executar-lo.

## **Opció 1: Botó “Run Python File”**

A dalt a la dreta del document apareix un botó ▶️ (executar).
Prem-lo i el programa es llançarà en una terminal integrada.

## **Opció 2: Terminal manual**

1. Ves a **Terminal → New Terminal**.
2. Escriu:

```
python3 hola.py
```

I l’ordinador executarà el programa, i mostrarà el missatge per consola.

---

## **7. Configurar Python Interpreter (si cal)**

A vegades, VS Code necessita saber quin Python utilitzar.
Si a dalt a la dreta et posa “Select Python Interpreter”:

1. Prem damunt. 
2. Tria **Python 3.x.x** de la ruta on el tens instal·lat.

Normalment VS Code ja ho detecta sol.

---

## **8. Crear exemple amb entrada i variables**

Crea un fitxer nou:

**nom.py**

Escriu:

```python
nom = input("Com et dius? ")
print("Encantat, " + nom)
```

Executa’l igual que abans.

---
## **Consells finals**: 

Hem de tindre en compte:

* Sempre guarda abans d’executar.
* Si un programa no funciona, revisa la **indentació** (espais).
* Fes servir fitxers curts i clars quan estigues començant.
* No poses espais en els noms dels fitxers (`hola_món.py` sí, `hola món.py` no).
