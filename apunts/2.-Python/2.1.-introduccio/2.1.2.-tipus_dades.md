# Variables i tipus de dades en Python

En les unitats anteriors hem aprés a dissenyar algoritmes amb pseudocodi i diagrames de flux. També hem preparat Visual Studio Code per a escriure i executar els nostres primers programes Python.

Ara aprendrem a **guardar, consultar i modificar informació utilitzant variables**.

Treballarem amb els tipus de dades bàsics de Python, les assignacions, les cadenes de text i les conversions entre tipus.

## 1. Variables i assignacions

Una **variable** és un nom que utilitzem per a identificar un valor dins d'un programa.

Les variables ens permeten guardar informació, consultar-la i modificar-la durant l'execució.

En pseudocodi ja hem utilitzat variables. La principal diferència és la sintaxi de l'assignació:

| Pseudocodi | Python |
|---|---|
| `edat ← 17` | `edat = 17` |
| `nom ← "Anna"` | `nom = "Anna"` |
| `preu ← 19.99` | `preu = 19.99` |

En Python utilitzem el símbol **`=` per a assignar un valor** a una variable.

### 1.1. Crear variables

Per a crear una variable, escrivim el seu nom, el símbol `=` i el valor que volem assignar-li.

```python
nom = "Anna"
edat = 17
altura = 1.68
```

En este exemple:

- `nom` conté el text `"Anna"`.
- `edat` conté el número enter `17`.
- `altura` conté el número decimal `1.68`.

Podem mostrar els seus valors utilitzant `print()`:

```python
nom = "Anna"
edat = 17
altura = 1.68

print(nom)
print(edat)
print(altura)
```

**Resultat:**

```text
Anna
17
1.68
```

### 1.2. Assignació i comparació

És important no confondre els operadors `=` i `==`.

| Operador | Funció | Exemple |
|---|---|---|
| `=` | Assigna un valor. | `edat = 17` |
| `==` | Comprova si dos valors són iguals. | `edat == 17` |

Per exemple:

```python
edat = 17

print(edat == 17)
```

**Resultat:**

```text
True
```

La primera instrucció assigna el valor `17` a la variable. La segona comprova si el seu valor és igual a `17`.

Estudiarem els operadors de comparació amb més profunditat en la unitat corresponent.

## 2. Tipus de dades bàsics

En Python, els valors poden ser de diferents tipus.

En esta unitat treballarem amb quatre tipus bàsics:

| Tipus | Nom en Python | Exemple | Utilització |
|---|---|---|---|
| Enter | `int` | `17`, `0`, `-5` | Edats, quantitats, comptadors. |
| Decimal | `float` | `3.14`, `-2.5` | Altures, pesos, preus. |
| Text | `str` | `"Anna"` | Noms, descripcions, codis. |
| Booleà | `bool` | `True`, `False` | Estats i condicions. |

Python determina el tipus d'un valor sense que hàgem de declarar-lo explícitament.

### 2.1. Números enters (`int`)

El tipus `int` representa números enters, és a dir, sense part decimal.

```python
edat = 17
alumnes = 25
temperatura = -3

print(edat)
print(alumnes)
print(temperatura)
```

**Resultat:**

```text
17
25
-3
```

Els enters s'utilitzen habitualment per a representar quantitats, edats o comptadors.

### 2.2. Números decimals (`float`)

El tipus `float` permet representar nombres de coma flotant, habitualment utilitzats per a treballar amb valors decimals.

```python
altura = 1.75
preu = 19.99
temperatura = -2.5

print(altura)
print(preu)
print(temperatura)
```

**Resultat:**

```text
1.75
19.99
-2.5
```

**Important:** en Python utilitzem el punt (`.`) com a separador decimal, no la coma.

```python
preu = 12.50  # Correcte
```

Els valors `float` són aproximacions binàries de nombres reals. Per això, algunes operacions poden produir xicotetes diferències de precisió.

En esta unitat no necessitem aprofundir en estos detalls, però convé saber que els decimals no sempre es representen de manera exacta.

### 2.3. Cadenes de text (`str`)

El tipus `str` representa una cadena de caràcters.

Els textos s'escriuen entre cometes simples (`' '`) o dobles (`" "`).

```python
nom = "Maria"
cognom = 'Garcia'
codi_postal = "12600"

print(nom)
print(cognom)
print(codi_postal)
```

**Resultat:**

```text
Maria
Garcia
12600
```

Encara que `"12600"` continga únicament xifres, és un text perquè està entre cometes.

Això és útil per a representar codis postals, números de telèfon o identificadors amb els quals no necessitem fer operacions matemàtiques.

### 2.4. Valors booleans (`bool`)

El tipus `bool` només pot tindre dos valors:

- `True`: cert.
- `False`: fals.

```python
matriculat = True
repetidor = False

print(matriculat)
print(repetidor)
```

**Resultat:**

```text
True
False
```

Els booleans són útils per a representar estats que només tenen dues possibilitats.

Per exemple:

```python
ordinador_encés = True
connexio_disponible = False
```

**Important:** `True` i `False` s'escriuen amb la primera lletra en majúscula i sense cometes.

Si escrivim `"True"` entre cometes, estem creant una cadena de text, no un valor booleà.

## 3. Comprovar el tipus d'una variable: `type()`

Python incorpora la funció `type()`, que permet conéixer el tipus d'un valor.

Observa este exemple:

```python
nom = "Anna"
edat = 17
altura = 1.68
matriculat = True

print(type(nom))
print(type(edat))
print(type(altura))
print(type(matriculat))
```

**Resultat:**

```text
<class 'str'>
<class 'int'>
<class 'float'>
<class 'bool'>
```

La funció `type()` resulta útil per a comprovar amb quin tipus de dades estem treballant.

### 3.1. El tipus pot canviar

En Python, una mateixa variable pot fer referència a valors de diferents tipus durant l'execució.

```python
x = 10

print(x)
print(type(x))

x = "Hola"

print(x)
print(type(x))
```

**Resultat:**

```text
10
<class 'int'>
Hola
<class 'str'>
```

En este exemple, `x` primer fa referència a un enter i després a una cadena de text.

Encara que Python ho permeta, **és recomanable mantindre un ús coherent de les variables**.

Per exemple, si `edat` representa una edat numèrica, no convé utilitzar després la mateixa variable per a guardar un nom.

## 4. Modificar i actualitzar variables

Les variables poden canviar de valor durant l'execució d'un programa.

### 4.1. Modificar un valor

Podem assignar un valor nou a una variable:

```python
edat = 17

print(edat)

edat = 18

print(edat)
```

**Resultat:**

```text
17
18
```

La segona assignació substituïx el valor anterior.

### 4.2. Actualitzar una variable

També podem calcular un valor nou utilitzant el valor actual de la mateixa variable.

```python
unitats = 12

unitats = unitats + 5

print(unitats)
```

**Resultat:**

```text
17
```

La instrucció:

```python
unitats = unitats + 5
```

funciona de la manera següent:

1. Python consulta el valor actual de `unitats`, que és `12`.
2. Calcula `12 + 5`.
3. Guarda el resultat, `17`, en `unitats`.

### 4.3. Seguiment de variables

Observa el programa següent:

```python
a = 5
b = 10

a = a + b
b = a - 3
a = b + 2

print(a, b)
```

Podem seguir l'evolució dels valors mitjançant una taula:

| Instrucció | a | b |
|---|---:|---:|
| Valors inicials | 5 | 10 |
| `a = a + b` | 15 | 10 |
| `b = a - 3` | 15 | 12 |
| `a = b + 2` | 14 | 12 |

**Resultat:**

```text
14 12
```

Este procediment és equivalent a les taules de seguiment que ja hem utilitzat amb pseudocodi.

**Recorda:** les instruccions s'executen en ordre. Cada assignació utilitza els valors que tenen les variables en eixe moment, no necessàriament els inicials.

## 5. Treballar amb cadenes de text

A més de guardar textos, Python permet combinar-los i mostrar-los de diferents maneres.

### 5.1. Concatenació amb `+`

La **concatenació** consistix a unir diverses cadenes de text.

En Python podem utilitzar l'operador `+`.

```python
nom = "Anna"
cognom = "Garcia"

nom_complet = nom + " " + cognom

print(nom_complet)
```

**Resultat:**

```text
Anna Garcia
```

Observa que hem afegit `" "` per a separar el nom i el cognom amb un espai.

#### Concatenar textos i números

Quan utilitzem `+` per a concatenar, els dos valors han de ser cadenes de text.

Este exemple és incorrecte:

```python
edat = 17

print("Edat: " + edat)
```

Produirà un `TypeError`, perquè intentem concatenar un text (`str`) amb un enter (`int`).

Per a solucionar-ho, podem convertir el número en text:

```python
edat = 17

print("Edat: " + str(edat))
```

**Resultat:**

```text
Edat: 17
```

També podem utilitzar `print()` amb diversos arguments separats per comes:

```python
print("Edat:", edat)
```

En este cas, no necessitem convertir manualment el número en text.

### 5.2. Cadenes formatades: `f-strings`

Les **f-strings** permeten combinar text i variables d'una manera clara i senzilla.

Per a utilitzar-les, escrivim la lletra `f` abans de les cometes i introduïm les variables entre claus `{}`.

```python
nom = "Pau"
edat = 18

print(f"Em dic {nom} i tinc {edat} anys")
```

**Resultat:**

```text
Em dic Pau i tinc 18 anys
```

Les f-strings també permeten introduir expressions:

```python
preu = 20
quantitat = 3

print(f"Preu total: {preu * quantitat} €")
```

**Resultat:**

```text
Preu total: 60 €
```

#### Comparació de les diferents formes

```python
nom = "Anna"
edat = 17

# Concatenació
print("Nom: " + nom + ", edat: " + str(edat))

# Diversos arguments
print("Nom:", nom, ", edat:", edat)

# f-string
print(f"Nom: {nom}, edat: {edat}")
```

Les tres formes permeten mostrar informació, encara que la presentació dels espais pot variar.

En general, **utilitzarem preferentment f-strings** quan necessitem combinar textos i variables, perquè solen resultar més llegibles.

### 5.3. Seqüències especials

Dins de les cadenes de text podem utilitzar caràcters especials per a controlar la presentació.

Els més habituals són:

| Seqüència | Funció |
|---|---|
| `\n` | Introduïx un salt de línia. |
| `\t` | Introduïx una tabulació. |
| `\'` | Permet incloure una cometa simple escapada. |
| `\"` | Permet incloure una cometa doble escapada. |

**Exemple:**

```python
print("Hola\nMón")
print("Nom:\tAnna")
```

**Resultat aproximat:**

```text
Hola
Món
Nom:    Anna
```

La separació visual produïda per `\t` depén de la configuració de les tabulacions del terminal.

També podem utilitzar cometes dins d'una cadena:

```python
print("Ella diu 'hola'")
print('Ell contesta: "bon dia"')
```

### 5.4. Textos de diverses línies

Python permet crear cadenes de text que ocupen diverses línies utilitzant triples cometes simples (`'''`) o dobles (`"""`).

```python
descripcio = """Ordinador de sobretaula.
Processador Intel Core i5.
Memòria RAM de 16 GB."""

print(descripcio)
```

**Resultat:**

```text
Ordinador de sobretaula.
Processador Intel Core i5.
Memòria RAM de 16 GB.
```

Les triples cometes són útils per a guardar textos llargs o descripcions.

**Important:** les triples cometes creen cadenes de text, no comentaris. Per a escriure comentaris utilitzarem el símbol `#`.

## 6. Conversió de tipus

En algunes situacions necessitarem transformar un valor d'un tipus a un altre.

Este procés s'anomena **conversió de tipus**.

Python incorpora diverses funcions per a realitzar conversions.

| Funció | Utilització | Exemple |
|---|---|---|
| `int()` | Convertix un valor compatible en enter. | `int("17")` |
| `float()` | Convertix un valor compatible en decimal. | `float("1.75")` |
| `str()` | Convertix un valor en text. | `str(17)` |

### 6.1. Convertir text en enter

```python
edat_text = "17"

edat = int(edat_text)

print(edat)
print(type(edat))
```

**Resultat:**

```text
17
<class 'int'>
```

### 6.2. Convertir text en decimal

```python
altura_text = "1.75"

altura = float(altura_text)

print(altura)
print(type(altura))
```

**Resultat:**

```text
1.75
<class 'float'>
```

### 6.3. Convertir números en text

```python
edat = 17

edat_text = str(edat)

print(edat_text)
print(type(edat_text))
```

**Resultat:**

```text
17
<class 'str'>
```

Encara que visualment `17` i `"17"` es mostren igual amb `print()`, són valors de tipus diferents.

### 6.4. Convertir decimals en enters

La funció `int()` també permet convertir un `float` en un enter.

```python
preu = 19.99

preu_enter = int(preu)

print(preu_enter)
```

**Resultat:**

```text
19
```

La funció `int()` elimina la part decimal per truncament cap a zero.

Per tant, **no arredonix el número**.

### 6.5. Errors de conversió

No tots els textos es poden convertir en números.

Per exemple:

```python
numero = int("hola")
```

Produirà un `ValueError`, perquè `"hola"` no representa un número enter vàlid.

Igualment:

```python
altura = float("abc")
```

També produirà un error.

Les conversions seran especialment importants quan treballem amb `input()`, ja que esta funció retorna les dades introduïdes per l'usuari com a text.

## 7. Intercanvi de valors

En alguns programes necessitarem **intercanviar el contingut de dues variables**, és a dir, fer que una variable adopte el valor de l'altra i viceversa.

Per exemple:

```python
a = 3
b = 8
```

Volem que, després de l'intercanvi:

- `a` valga `8`.
- `b` valga `3`.

### 7.1. Mètode clàssic: variable auxiliar

La primera solució que podríem pensar seria:

```python
a = b
b = a
```

**Però esta solució és incorrecta.**

Quan executem `a = b`, el valor original de `a` es perd. Al final, les dues variables contindrien el valor `8`.

Per a evitar-ho, utilitzem una **variable auxiliar** que guarde temporalment un dels valors.

```python
a = 3
b = 8

aux = a
a = b
b = aux
```

**Explicació pas a pas:**

| Instrucció | a | b | aux | Explicació |
|---|---:|---:|---:|---|
| Valors inicials | 3 | 8 | — | Situació inicial. |
| `aux = a` | 3 | 8 | 3 | Guardem el valor original de `a`. |
| `a = b` | 8 | 8 | 3 | Copiem el valor de `b` en `a`. |
| `b = aux` | 8 | 3 | 3 | Recuperem el valor original de `a`. |

D'esta manera hem intercanviat correctament els valors sense perdre'n cap.

### 7.2. Mètode de Python: assignació múltiple

Python permet realitzar este intercanvi d'una manera més compacta, sense necessitat d'utilitzar una variable auxiliar explícita.

```python
a = 3
b = 8

a, b = b, a
```

Python avalua primer les expressions de la dreta i després assigna els resultats a les variables de l'esquerra.

Per tant:

- `a` passa a valdre `8`.
- `b` passa a valdre `3`.

### 7.3. Exemple complet

```python
x = 100
y = 250

print("Abans de l'intercanvi:", x, y)

x, y = y, x

print("Després de l'intercanvi:", x, y)
```

**Resultat:**

```text
Abans de l'intercanvi: 100 250
Després de l'intercanvi: 250 100
```

**Important:** els dos mètodes són correctes. El mètode amb variable auxiliar ajuda a comprendre les assignacions, mentre que l'assignació múltiple és més compacta i habitual en Python.

## 8. Noms de variables i bones pràctiques

Per a escriure programes clars i fàcils de mantindre, és important utilitzar noms de variables adequats.

### 8.1. Regles dels noms de variables

En Python:

- Els noms no poden començar per un número.
- Poden contindre lletres, números i guions baixos (`_`).
- No poden contindre espais ni guions (`-`).
- Diferencien majúscules i minúscules.
- No podem utilitzar paraules reservades del llenguatge, com `if`, `for` o `while`.

Exemples correctes:

```python
edat = 17
nom_alumne = "Anna"
preu_total = 25.50
unitats_disponibles = 10
```

Exemples incorrectes:

```python
2edat = 17
nom alumne = "Anna"
preu-total = 25.50
```

En l'últim cas, Python interpreta `-` com un operador de resta, no com una part del nom.

### 8.2. Utilitzar `snake_case`

En Python és habitual escriure els noms de variables en minúscules i separar les paraules amb guions baixos.

Este estil s'anomena **snake_case**.

```python
nom_alumne = "Pau"
nota_mitjana = 8.5
preu_final = 19.99
```

Encara que Python admet molts caràcters Unicode en els identificadors, en este curs utilitzarem preferentment noms sense accents per a facilitar la lectura i evitar problemes de compatibilitat.

### 8.3. Noms descriptius

És preferible utilitzar noms que indiquen quina informació contenen.

**Poc descriptiu:**

```python
x = 25
y = 3
z = x * y
```

**Més descriptiu:**

```python
preu = 25
quantitat = 3
total = preu * quantitat
```

Els dos programes poden realitzar el mateix càlcul, però el segon és més fàcil de comprendre.

### 8.4. Comentaris

Els comentaris permeten afegir explicacions al codi.

```python
# Calculem el valor total dels productes
preu = 25
quantitat = 3

total = preu * quantitat

print(total)
```

No és necessari comentar totes les instruccions. Els comentaris han d'ajudar a comprendre el funcionament del programa.

## 9. Resum

### 9.1. Tipus de dades

| Tipus | Exemple | Descripció |
|---|---|---|
| `int` | `17` | Número enter. |
| `float` | `19.99` | Número de coma flotant. |
| `str` | `"Anna"` | Cadena de text. |
| `bool` | `True` | Valor booleà. |

### 9.2. Operacions bàsiques amb variables

| Operació | Exemple | Funció |
|---|---|---|
| Assignació | `a = 5` | Guarda un valor. |
| Actualització | `a = a + 1` | Modifica el valor anterior. |
| Comprovació del tipus | `type(a)` | Consulta el tipus. |
| Conversió a enter | `int("17")` | Convertix en enter. |
| Conversió a decimal | `float("1.75")` | Convertix en `float`. |
| Conversió a text | `str(17)` | Convertix en cadena. |
| Concatenació | `"Hola " + nom` | Unix cadenes de text. |
| f-string | `f"Hola {nom}"` | Combina text i expressions. |
| Intercanvi | `a, b = b, a` | Intercanvia dos valors. |

### 9.3. Idees importants

- Les variables permeten identificar i reutilitzar valors.
- Python determina el tipus dels valors automàticament.
- Podem modificar variables mitjançant noves assignacions.
- L'ordre d'execució és fonamental quan actualitzem variables.
- Les cadenes de text poden concatenar-se o combinar-se amb `f-strings`.
- Les conversions permeten transformar valors entre tipus compatibles.
- Per a intercanviar valors podem utilitzar una variable auxiliar o assignació múltiple.
- Els noms descriptius i les bones pràctiques faciliten la comprensió del codi.
