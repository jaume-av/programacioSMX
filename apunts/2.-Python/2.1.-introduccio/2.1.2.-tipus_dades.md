# Tipus de dades i variables en Python**

A continuació es presenten els elements més bàsics del llenguatge Python: 

- **tipus de dades**
- **variables**
- **conversions**
- **comentaris**. 

Estos conceptes són la base de tots els programes que escriurem en Visual Studio Code.

>Hem de tindre en compte que Python és un llenguatge senzill i flexible. Ens permet concentrar-nos en la lògica del programa sense preocupar-nos massa per detalls tècnics.

---

## **1. Comentaris**

Els comentaris ens ajuden a entendre què fa un programa. Python els ignora quan executa el codi.

### Comentari d'una línia

Escrivim el símbol numeral:

```python
# Este és un comentari
print("Hola món")
```

### Comentari de diverses línies

Podem utilitzar tres cometes simples:

```python
'''
Comentari llarg
de diverses línies
'''
print("Execució")
```

---

## **2. Tipus de dades bàsics**

Python treballa principalment amb tres tipus de dades: **(números, textos i booleans)**.

### **2.1. Números**

Poden ser:

* **enters:** 4, 0, -12
* **reals (float):** 3.14, -0.5

S’utilitzen per a operacions matemàtiques.

### **2.2. Textos (strings)**

Qualsevol cosa entre cometes simples o dobles es considera text:

```python
nom = "Anna"
cognom = 'Aragó'
```

També podem utilitzar seqüències especials:

* `\n` → salt de línia
* `\t` → tabulació

### **2.3. Booleans**

Només poden tindre dos valors:

* True
* False

Els utilitzarem en condicions i comparacions.

---

## **3. Variables**

Una variable és un nom que utilitzem per guardar informació.

Python no necessita que indiquem el tipus:

```python
edat = 17
nom = "Maria"
nota = 8.2
```

### Intercanvi de valors

En alguns programes necessitarem intercanviar el contingut de dues variables, és a dir, fer que la variable A tinga el valor de B i que B tinga el valor de A. En molts llenguatges de programació este procés és un poc més llarg i cal utilitzar una variable auxiliar.


En Python, però, este intercanvi és **molt més senzill**, perquè el llenguatge permet assignar diversos valors alhora utilitzant una sintaxi clara i compacta.

```python
a = 3
b = 8
a, b = b, a
```

Després d’esta instrucció:

- **a** valdrá **8**
- **b** valdrá **3**

**Exemple complet:**

```python
x = 100
y = 250

print("Abans de l'intercanvi:", x, y)

x, y = y, x

print("Després de l'intercanvi:", x, y)
```
Este programa ens mostrarà:

```rust
Abans de l'intercanvi: 100 250
Després de l'intercanvi: 250 100

```

---

## **4. Noms de variables: bones pràctiques**

Normes generals:

* No poden començar per un número.
* Només poden contindre lletres, números i guions baixos.
* No utilitzes espais ni accents.

En Python és habitual utilitzar **snake_case** (lletres minúscules i guions baixos):

```python
numero = 10
nom_alumne = "Javi"
num_llibreta = 5
```

---

## **5. Conversió de tipus**

De vegades necessitem convertir un valor d’un tipus a un altre. Python permet fer conversions senzilles amb tres funcions bàsiques:

```python
int(valor)    # Convertix un text o decimal en enter
float(valor)  # Convertix un text en decimal
str(valor)    # Convertix qualsevol valor en text
```

Açò és útil quan treballem amb dades que arriben com a text i després necessitem utilitzar-les en operacions matemàtiques. Més avant, en l’apartat d’Entrada i eixida, veurem per què aquestes conversions són necessàries.

Exemple simple:

```python
numero = int("23")
altura = float("1.75")
edat_text = str(17)
```

# **2.1.3 Operadors en Python**

En esta unitat aprendrem a fer operacions matemàtiques i comparacions. Estos operadors ens permetran crear programes que calculen, decideixen i comproven condicions.

---

## **1. Operadors aritmètics**

Python ofereix estes operacions bàsiques:

| Operador | Significat     |
| -------- | -------------- |
| +        | Suma           |
| -        | Resta          |
| *        | Multiplicació  |
| /        | Divisió        |
| //       | Divisió entera |
| %        | Mòdul (rest)   |
| **       | Potència       |

Exemples:

```python
x = 10
y = 3

print(x + y)     # 13
print(x / y)     # 3.333...
print(x // y)    # 3
print(x % y)     # 1
print(x ** y)    # 1000
```

---

## **2. Operadors relacionals**

Comparen dos valors i tornen True o False:

| Operador | Significat    |
| -------- | ------------- |
| ==       | Igual         |
| !=       | Diferent      |
| <        | Menor         |
| <=       | Menor o igual |
| >        | Major         |
| >=       | Major o igual |

Exemple:

```python
edat = 18
print(edat >= 18)  # True
```

---

## **3. Operadors lògics**

Ens permeten combinar condicions:

| Operador | Significat                   |
| -------- | ---------------------------- |
| and      | Les dues condicions són True |
| or       | Almenys una condició és True |
| not      | Inverteix True/False         |

Exemples:

```python
print(3 > 2 and 5 > 1)   # True
print(3 > 4 or 2 > 1)    # True
print(not False)         # True
```

---

## **4. Errors habituals**

És important reconéixer alguns errors bàsics:

### IndentationError (espais incorrectes)

```python
if True:
print("hola")   # Incorrecte
```

Solució:

```python
if True:
    print("hola")
```

### NameError (variable no definida)

```python
print(x)   # x no existeix
```

### TypeError (sumar text i número)

```python
edat = int(input("Edat: "))
print("Tens " + edat + " anys")  # Error
```

Solució:

```python
print("Tens", edat, "anys")
```

# **2.1.4 Entrada i eixida en Python + Exercicis**

En esta unitat aprendrem a mostrar informació i a demanar dades a l’usuari. És la base per crear programes interactius.

---

## **1. Mostrar informació amb print**

Python permet mostrar textos, variables i expressions.

```python
print("Hola món")
nom = "Anna"
print("Hola", nom)
```

Podem canviar el separador:

```python
print(2, 4, 6, sep="-")  # 2-4-6
```

La manera recomanada per intercalar variables és utilitzar f-strings:

```python
nom = "Pau"
edat = 16
print(f"{nom} té {edat} anys")
```

---

## **2. Demanar informació a l’usuari**

La funció `input()` mostra un missatge i espera que l’usuari escriga alguna cosa.

Sempre retorna un text.

### Exemple bàsic

```python
nom = input("Com et dius? ")
print("Encantat,", nom)
```

### Exemple amb números

```python
a = int(input("Primer número: "))
b = int(input("Segon número: "))
print("La suma és:", a + b)
```

### Exemple amb decimals

```python
nota = float(input("Escriu la teua nota: "))
print("Has tret un", nota)
```
