# 2.1.1. Python i Visual Studio Code 

En este apartat aprendrem a utilitzar **Visual Studio Code** (VS Code) per a crear, guardar i executar els nostres primers programes en **Python**.

Utilitzarem Ubuntu o LliureX i treballarem amb fitxers `.py`.

## 1. Què necessitem?

Per a programar en Python utilitzarem dues ferramentes:

| Ferramenta         | Funció                                                                     |
| ------------------ | -------------------------------------------------------------------------- |
| Python 3           | És el llenguatge de programació. El seu intèrpret executa els programes.   |
| Visual Studio Code | És l'editor que utilitzarem per a escriure, organitzar i executar el codi. |

### 1.1. Comprovar Python

Obri el terminal amb `Ctrl + Alt + T` i escriu:

```
python3 --version
```

Si apareix una versió de **Python 3**, ja està instal·lat.

Si no està instal·lat, consulta el professor abans de continuar.

### 1.2. Preparar VS Code

1. Obri Visual Studio Code.
2. Accedix a Extensions (`Ctrl + Shift + X`).
3. Busca l'extensió Python, de Microsoft, i instal·la-la si no està instal·lada.
4. Obri la paleta d'ordres (`Ctrl + Shift + P`).
5. Busca `Python: Select Interpreter` i selecciona Python 3.

En Ubuntu o LliureX, l'intèrpret sol estar en `/usr/bin/python3`.

## 2. Crear un projecte Python

En VS Code, per als nostres primers programes, **un projecte serà simplement una carpeta que contindrà els fitxers** Python relacionats.

No necessitem crear cap estructura especial, instal·lar biblioteques ni configurar entorns virtuals per a estes primeres activitats.

### 2.1. Crear la carpeta del projecte

Crea una carpeta anomenada `Python` i, dins, una altra anomenada `01_Introduccio`.

```
Python/
└── 01_Introduccio/
```

### 2.2. Obrir el projecte en VS Code

1. Selecciona **File → Open Folder**.
2. Busca la carpeta `01_Introduccio`.
3. Prem **Open**.

A partir d'ara, esta carpeta serà el nostre projecte de treball.

Important: és preferible obrir la carpeta completa en VS Code, en lloc d'obrir cada fitxer per separat. Així podrem organitzar els programes i treballar amb el terminal en el mateix directori.

## 3. Crear un programa Python

Els programes Python es guarden en fitxers amb l'extensió `.py`.

### 3.1. Crear un fitxer

1. En l'explorador de VS Code, prem New File.
2. Escriu `hola_mon.py`.
3. Prem `Enter`.

Utilitzarem noms de fitxer descriptius, preferiblement en minúscules, sense espais i separant les paraules amb guions baixos (`_`).

Per exemple:

```
hola_mon.py
calculadora.py
practica_01.py
```

### 3.2. Escriure el primer programa

Dins del fitxer `hola_mon.py`, escriu:

```
# El meu primer programa en Pythonprint("Hola, món!")print("Estic aprenent Python")
```

La instrucció `print()` permet mostrar informació per pantalla.

El símbol `#` introduïx un comentari, que Python ignora quan executa el programa.

Guarda el fitxer amb `Ctrl + S`.

## 4. Executar un programa

Podem executar el programa de dues maneres.

### 4.1. Des de VS Code

Amb el fitxer `hola_mon.py` obert, prem el botó Run Python File (triangle de reproducció) de la part superior de l'editor.

VS Code obrirà un terminal i mostrarà el resultat:

```
Hola, món!
Estic aprenent Python
```

### 4.2. Des del terminal

Obri el terminal integrat de VS Code des de Terminal → New Terminal.

Si el terminal està situat en la carpeta del projecte, escriu:

```
python3 hola_mon.py
```

Obtindràs el mateix resultat.

## 5. Organitzar els programes

Cada programa pot estar en un fitxer `.py` diferent dins del mateix projecte.

Per exemple:

```
Python/
├── 01_Introduccio/
│   ├── hola_mon.py
│   ├── presentacio.py
│   └── calculs.py
├── 02_Variables/
│   ├── variables.py
│   └── tipus_dades.py
└── 03_Operadors/
    └── operacions.py
```

Per a treballar en una altra unitat, podem obrir la carpeta corresponent en VS Code.

No cal crear un projecte nou per a cada programa. Podem tindre diversos fitxers `.py` dins de la mateixa carpeta.

## 6. Errors habituals

| Problema                                            | Possibles causes i solucions                                     |
| --------------------------------------------------- | ---------------------------------------------------------------- |
| Python no s'executa                                 | Comprova `python3 --version` i l'intèrpret seleccionat.          |
| El programa no mostra els últims canvis             | Guarda el fitxer amb `Ctrl + S`.                                 |
| Python no troba el fitxer                           | Comprova el nom i la carpeta on es troba.                        |
| `SyntaxError`                                       | Revisa cometes, parèntesis i altres elements de la sintaxi.      |
| `NameError` amb `Print`                             | Escriu `print` en minúscules.                                    |
| Apareixen cometes incorrectes en la ruta d'execució | Revisa l'ordre generada per VS Code o les extensions d'execució. |

Quan aparega un error, llig el missatge del terminal, localitza el problema, corregix-lo i torna a executar el programa.

## 7. Activitats pràctiques

### Activitat 1. Crear i executar un programa

Crea un fitxer anomenat `presentacio.py` dins de la carpeta `01_Introduccio`.

Escriu un programa que mostre el resultat següent:

```
Hola, soc alumne de 2n de SMX.
Estic aprenent Python.
Este és el meu primer programa.
```

Requisits:

1. Utilitza tres instruccions `print()`.
2. Afig un comentari al principi que explique què fa el programa.
3. Guarda el fitxer.
4. Executa'l des del botó de VS Code.
5. Executa'l també des del terminal.

### Activitat 2. Predir i modificar

Crea un fitxer anomenat `operacions.py` amb este codi:

```
print("Operacions amb Python")print(10 + 5)print("10 + 5")print(4 * 3)
```

Abans d'executar-lo, escriu quin resultat creus que mostrarà.

Després, executa'l i comprova la teua predicció.

Modifica el programa perquè calcule també `100 - 25` i `8 * 6`, i mostra un missatge final.

### Activitat 3. Localitzar i corregir errors

Crea un fitxer anomenat `errors.py`.

Copia el següent programa, que conté tres errors:

```
Print("Benvinguts a Python")print("Estic aprenent a programar)print(10 + 5
```

Què has de fer?

1. Identifica els tres errors sense executar el programa.
2. Corregix-los.
3. Guarda el fitxer.
4. Executa'l i comprova que funciona.
