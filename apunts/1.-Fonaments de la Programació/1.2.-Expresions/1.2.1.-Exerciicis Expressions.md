# Pràctica: Variables, operadors i expressions

## Exercici 1. Variables i constants

Indica si els elements següents haurien de representar-se mitjançant una variable o una constant. Justifica breument la resposta.

1. La puntuació acumulada per un jugador durant una partida.
2. El nombre de dies que té una setmana.
3. La temperatura que registra un sensor cada minut.
4. El percentatge de descompte fix establit per a una promoció.

## Exercici 2. Seguiment de variables

Donats els valors inicials `A ← 11`, `B ← 5` i `C ← 3`, completa la taula indicant el valor de les variables després d'executar cada instrucció.

| Instrucció       | A  | B | C |
| ---------------- | -- | - | - |
| Valors inicials  | 11 | 5 | 3 |
| `A ← A - B`      |    |   |   |
| `C ← A + C`      |    |   |   |
| `B ← C // 2`     |    |   |   |
| `A ← B * C`      |    |   |   |
| `C ← A % 5`      |    |   |   |
| `B ← B + C ** 2` |    |   |   |

## Exercici 3. Expressions aritmètiques

Calcula el resultat de les expressions següents, respectant la prioritat dels operadors.

1. `27 - 5 * 3 + 8`
2. `(16 + 8) / 4 + 3 ** 2`
3. `43 // 6 + 43 % 6`
4. `60 - (4 + 2) ** 2`
5. `(35 % 8 + 5) * (18 // 5)`
6. `-3 ** 2 + (-3) ** 2 * 4`
7. `2 ** 3 ** 2 // 9 + 7`
8. `((48 / 6 - 3) ** 2 + 15) / 5`

## Exercici 4. Expressions relacionals i lògiques

Avalua les expressions següents. Indica si el resultat és `CERT` o `FALS` i mostra els passos intermedis.

1. `18 + 7 > 5 ** 2`
2. `32 % 7 == 32 // 7`
3. `NOT (12 < 8)`
4. `CERT OR FALS AND FALS`
5. `(15 // 4 == 3) AND (15 % 4 != 3)`
6. `NOT (6 * 3 <= 18 AND 5 ** 2 > 20)`
7. `(24 / 6 == 4) OR NOT (17 % 5 == 2)`
8. `NOT (9 + 4 < 15 OR 3 ** 2 >= 10) AND 20 // 6 == 3`

## Exercici 5. Expressions amb variables i constants

Donats els valors següents:

```
a ← 6
b ← 4
c ← 13

LIMIT ← 20
BONUS ← 5
```

Calcula el resultat de les expressions següents:

1. `(a + b) * BONUS - c`
2. `(LIMIT - c) ** 2 // b`
3. `a * b >= LIMIT AND c % b == 1`
4. `NOT (a + BONUS > c) OR b ** 2 == LIMIT - b`
5. `(c // a + b) * 3 <= LIMIT`
6. `(a ** 2 - c * 2 > BONUS) AND NOT (c % a == 0)`

## Exercici 6. Expressions combinades

Avalua les expressions següents, respectant la prioritat dels operadors. Mostra els resultats parcials fins a obtindre el resultat final.

1. `NOT (25 % 6 == 1) OR (3 ** 3 > 20 AND 8 // 3 == 2)`
2. `((7 + 5) ** 2 - 24) / 6 >= 20 AND NOT (18 % 4 == 0)`
3. `("Bon" + " dia" == "Bon dia") AND NOT ("A" == "a")`
4. `(48 // 7 + 3 ** 2 >= 15) AND NOT (29 % 6 > 4)`
5. `NOT ((18 + 6) / 4 < 7 OR 5 ** 2 == 20) AND (17 % 3 != 1)`
6. `((9 - 3) ** 2 / 4 == 9 OR 14 // 5 > 3) AND NOT (8 * 2 <= 15)`

## Exercici 7. Detecta els errors

Un alumne ha resolt les expressions següents. Indica si el resultat proposat és correcte o incorrecte. Si és incorrecte, explica quin error ha comés i calcula el resultat adequat.
