# 1.2. Elements bàsics d'un programa

Un programa utilitza variables, constants, expressions i operadors per a guardar dades, realitzar càlculs i comprovar condicions.

## 1. Variables i constants

Una variable és un espai identificat amb un nom que permet guardar un valor que pot canviar durant l'execució d'un programa.

Una constant representa un valor que ha de mantindre's fix durant l'execució.

| Element  | Característica            | Exemple         |
| -------- | ------------------------- | --------------- |
| Variable | El seu valor pot canviar  | `edat ← 16`     |
| Constant | El seu valor es manté fix | `PI ← 3.141592` |

Els identificadors han de ser clars i descriptius. Utilitzarem habitualment minúscules per a les variables (`nota_final`) i majúscules per a les constants (`IVA`).

## 2. Assignacions

Una assignació consisteix a guardar un valor o el resultat d'una expressió en una variable.

En pseudocodi utilitzarem el símbol `←`.

```
edat ← 16
edat ← edat + 1
```

En la segona instrucció, primer es calcula `16 + 1` i després es guarda el resultat `17` en `edat`.

### Exemple: seguiment de variables

Considerem les instruccions següents:

```
A ← 4
B ← 2
C ← 3

A ← B
C ← A
B ← (A + B + C) / 2
A ← A + C
```

Podem seguir els canvis mitjançant una taula de traça:

| Instrucció            | A | B | C |
| --------------------- | - | - | - |
| Valors inicials       | 4 | 2 | 3 |
| `A ← B`               | 2 | 2 | 3 |
| `C ← A`               | 2 | 2 | 2 |
| `B ← (A + B + C) / 2` | 2 | 3 | 2 |
| `A ← A + C`           | 4 | 3 | 2 |

Important: les instruccions s'executen en ordre. Cada operació utilitza els valors actuals de les variables, no els inicials.

## 3. Expressions

Una expressió és una combinació de valors, variables i operadors que, en ser avaluada, produeix un resultat.

Segons el tipus de resultat, distingim:

| Tipus             | Resultat        | Exemple                        |
| ----------------- | --------------- | ------------------------------ |
| Numèrica          | Un número       | `(5 + 3) * 2` → `16`           |
| Alfanumèrica      | Un text         | `"Bon " + "dia"` → `"Bon dia"` |
| Booleana o lògica | `CERT` o `FALS` | `5 > 3` → `CERT`               |

Les expressions poden utilitzar números enters (`5`, `-2`), reals (`3.5`), textos (`"Hola"`) i valors lògics (`CERT`, `FALS`).

Els decimals s'escriuen amb un punt i els textos entre cometes.

## 4. Operadors

Els operadors són símbols o paraules que indiquen quina operació volem realitzar.

Per exemple, en `5 + 3`, el símbol `+` és l'operador i els números `5` i `3` són els operands.

### 4.1. Operadors aritmètics

Permeten realitzar operacions matemàtiques.

| Operador | Operació             | Exemple  | Resultat |
| -------- | -------------------- | -------- | -------- |
| `+`      | Suma                 | `5 + 3`  | `8`      |
| `-`      | Resta                | `8 - 3`  | `5`      |
| `*`      | Multiplicació        | `4 * 3`  | `12`     |
| `/`      | Divisió real         | `7 / 2`  | `3.5`    |
| `//`     | Divisió entera       | `7 // 2` | `3`      |
| `%`      | Residu de la divisió | `7 % 2`  | `1`      |
| `**`     | Potència             | `2 ** 3` | `8`      |

Diferència entre `/`, `//` i `%`:

| Expressió | Resultat | Significat                   |
| --------- | -------- | ---------------------------- |
| `17 / 5`  | `3.4`    | Quocient real                |
| `17 // 5` | `3`      | Quocient arrodonit cap avall |
| `17 % 5`  | `2`      | Residu de la divisió         |

Per exemple, si repartim 17 objectes en grups de 5, podem formar 3 grups complets i sobren 2 objectes.

L'operador `%` també permet comprovar si un número enter és parell: `numero % 2 == 0`.

Observacions:

- La divisió `/` dona un resultat real: `8 / 2 → 4.0`.
- La divisió `//` arrodoneix cap avall: `-7 // 2 → -4`.
- La divisió entre zero no està definida.
- Utilitzarem `**` per a les potències, no `^`.

### 4.2. Operadors relacionals

Permeten comparar dos valors. El resultat sempre és `CERT` o `FALS`.

| Operador | Significat        | Exemple  | Resultat |
| -------- | ----------------- | -------- | -------- |
| `==`     | Igual que         | `5 == 5` | CERT     |
| `!=`     | Diferent de       | `5 != 3` | CERT     |
| `>`      | Major que         | `7 > 3`  | CERT     |
| `<`      | Menor que         | `3 < 7`  | CERT     |
| `>=`     | Major o igual que | `5 >= 5` | CERT     |
| `<=`     | Menor o igual que | `8 <= 6` | FALS     |

No hem de confondre assignació i comparació:

```
edat ← 18    // Guarda el valor 18
edat == 18   // Comprova si edat és igual a 18
```

Els textos també es poden comparar. Les majúscules i minúscules es diferencien:

```
"Anna" == "Anna" → CERT
"Anna" == "anna" → FALS
```

En les comparacions d'ordre entre textos, Python utilitza l'ordre Unicode dels caràcters, que no sempre coincideix amb l'ordre alfabètic habitual.

### 4.3. Operadors lògics o booleans

Permeten combinar o negar condicions. Treballen amb valors lògics: `CERT` i `FALS`.

| Operador | Nom       | Significat                            |
| -------- | --------- | ------------------------------------- |
| `NOT`    | Negació   | Inverteix el resultat d'una condició  |
| `AND`    | Conjunció | Les dues condicions han de ser certes |
| `OR`     | Disjunció | Almenys una condició ha de ser certa  |

Les taules de veritat mostren tots els resultats possibles de cada operador.

#### Operador NOT — Negació

Inverteix el valor lògic d'una expressió.

| A    | NOT A |
| ---- | ----- |
| CERT | FALS  |
| FALS | CERT  |

Exemple:

```
sancionat ← FALS

NOT sancionat → CERT
```

#### Operador AND — Conjunció

Retorna `CERT` únicament quan les dues condicions són certes.

| A    | B    | A AND B |
| ---- | ---- | ------- |
| CERT | CERT | CERT    |
| CERT | FALS | FALS    |
| FALS | CERT | FALS    |
| FALS | FALS | FALS    |

Exemple: una persona pot conduir si té almenys 18 anys i disposa del carnet corresponent.

```
edat ← 20
te_carnet ← CERT

edat >= 18 AND te_carnet → CERT
```

#### Operador OR — Disjunció

Retorna `CERT` quan almenys una condició és certa.

| A    | B    | A OR B |
| ---- | ---- | ------ |
| CERT | CERT | CERT   |
| CERT | FALS | CERT   |
| FALS | CERT | CERT   |
| FALS | FALS | FALS   |

Exemple: una persona pot participar en una activitat si és major d'edat o té autorització.

```
edat ← 16
te_autoritzacio ← CERT

edat >= 18 OR te_autoritzacio → CERT
```

Recorda: `AND` exigeix totes les condicions; `OR` exigeix almenys una; `NOT` inverteix el resultat.

### 4.4. Operadors alfanumèrics

La concatenació consisteix a unir textos per a formar-ne un de nou. Utilitzem l'operador `+`.

| Expressió         | Resultat     |
| ----------------- | ------------ |
| `"Hola " + "Món"` | `"Hola Món"` |
| `"Bon" + "dia"`   | `"Bondia"`   |
| `"5" + "3"`       | `"53"`       |

Per tant, sumar números no és el mateix que concatenar textos:

```
5 + 3       → 8
"5" + "3"   → "53"
```

En Python, no podem concatenar directament un text i un número amb `+` sense convertir prèviament el número a text.

## 5. Prioritat dels operadors

Quan una expressió conté diversos operadors, s'avaluen segons un ordre de prioritat o precedència.

### Taula de prioritat

De major a menor prioritat:

| Prioritat | Operadors                        | Operació                          |
| --------- | -------------------------------- | --------------------------------- |
| 1         | `()`                             | Agrupació amb parèntesis          |
| 2         | `**`                             | Potència                          |
| 3         | `*`, `/`, `//`, `%`              | Multiplicació, divisions i residu |
| 4         | `+`, `-`                         | Suma, resta i concatenació        |
| 5         | `<`, `<=`, `>`, `>=`, `==`, `!=` | Comparacions                      |
| 6         | `NOT`                            | Negació lògica                    |
| 7         | `AND`                            | Conjunció                         |
| 8         | `OR`                             | Disjunció                         |

Aquesta taula recull la precedència dels operadors que utilitzarem en els exercicis. Les comparacions tenen el mateix nivell general en Python i poden encadenar-se; per a facilitar-ne la lectura, utilitzarem parèntesis quan siga convenient.

Regles importants:

- Els parèntesis permeten modificar l'ordre habitual d'avaluació.
- Els operadors aritmètics de la mateixa prioritat s'agrupen habitualment d'esquerra a dreta.
- Les potències s'agrupen de dreta a esquerra: `2 ** 3 ** 2 → 512`.
- La potència té prioritat sobre el signe negatiu situat a l'esquerra: `-2 ** 2 → -4`, però `(-2) ** 2 → 4`.

### Exemple 1. Expressió aritmètica

Calculem:

```
((3 + 2) ** 2 - 15) / 2 * 5
```

| Pas | Operació      | Expressió               |
| --- | ------------- | ----------------------- |
| 1   | Parèntesi     | `(5 ** 2 - 15) / 2 * 5` |
| 2   | Potència      | `(25 - 15) / 2 * 5`     |
| 3   | Resta         | `10 / 2 * 5`            |
| 4   | Divisió       | `5.0 * 5`               |
| 5   | Multiplicació | `25.0`                  |

Resultat: `25.0`

### Exemple 2. Expressió lògica

Calculem:

```
5 - 2 > 4 AND NOT (0.5 == 1 / 2)
```

| Pas | Operació        | Resultat |
| --- | --------------- | -------- |
| 1   | `5 - 2`         | `3`      |
| 2   | `1 / 2`         | `0.5`    |
| 3   | `3 > 4`         | FALS     |
| 4   | `0.5 == 0.5`    | CERT     |
| 5   | `NOT CERT`      | FALS     |
| 6   | `FALS AND FALS` | FALS     |

Resultat: `FALS`

Notació que utilitzarem en els exercicis: assignació `←`, igualtat `==`, desigualtat `!=`, potència `**` i valors lògics `CERT` i `FALS`. En pseudocodi escriurem `NOT`, `AND` i `OR`; quan comencem Python, utilitzarem `not`, `and`, `or`, `True` i `False`.
