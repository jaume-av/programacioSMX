# Exercicis: Estructures repetitives — Bucles

En aquesta pràctica treballarem els bucles `MENTRE` en pseudocodi i la seua representació mitjançant diagrames de flux.

L'objectiu és comprendre com es repetixen les instruccions, com canvien les variables i quan acaba un bucle.

## Exercici 1. Què mostrarà el programa?

Observa el pseudocodi següent:

```
INICI

    numero ← 3

    MENTRE numero < 12 FER
        MOSTRAR numero
        numero ← numero + 3
    FI_MENTRE

FI
```

Respon:

1. Quins números mostrarà?
2. Quantes vegades s'executarà el bucle?
3. Quin valor tindrà `numero` quan acabe?
4. Per què no es mostra el número 12?

## Exercici 2. Completa la taula de seguiment

Observa el pseudocodi:

```
INICI

    comptador ← 10

    MENTRE comptador > 4 FER
        MOSTRAR comptador
        comptador ← comptador - 2
    FI_MENTRE

FI
```

Completa la taula indicant el valor de la variable, el resultat de la condició i l'acció que es realitza.

| Iteració | Comptador | `comptador > 4` | Acció     |
| -------- | --------- | --------------- | --------- |
| 1        | 10        | CERT            | Mostra 10 |
| 2        |           |                 |           |
| 3        |           |                 |           |
| 4        |           |                 |           |

Pregunta: quantes vegades es comprova la condició i quantes vegades s'executa el bucle?

## Exercici 3. Detecta l'error

Un alumne ha escrit aquest pseudocodi per mostrar els números de l'1 al 5:

```
INICI

    comptador ← 1

    MENTRE comptador <= 5 FER
        MOSTRAR comptador
    FI_MENTRE

FI
```

Respon:

1. Què passarà quan s'execute?
2. Quin error ha comés l'alumne?
3. Escriu el pseudocodi corregit perquè mostre els números de l'1 al 5 i acabe correctament.

## Exercici 4. Del pseudocodi al diagrama de flux

Observa el programa següent:

```
INICI

    numero ← 2

    MENTRE numero <= 10 FER
        MOSTRAR numero
        numero ← numero + 2
    FI_MENTRE

FI
```

Dibuixa el diagrama de flux corresponent.

El diagrama ha d'incloure:

- Inici i final.
- Inicialització de la variable.
- Rombe amb la condició.
- Camins `SÍ` i `NO`.
- Instruccions que es repetixen.
- Fletxa que torna a comprovar la condició.

Pregunta: què passaria si canviàrem `numero ← numero + 2` per `numero ← numero + 3`? Indica quins valors es mostrarien.

## Exercici 5. Escriu el pseudocodi

Volem crear un algorisme que mostre els números del 5 al 1, en ordre descendent.

El resultat ha de ser:

```
5
4
3
2
1
```

Escriu el pseudocodi complet utilitzant un bucle `MENTRE`.

Pregunta: quin valor tindrà el comptador quan acabe el bucle?

## Exercici 6. Analitza les condicions

Observa els tres fragments següents.

Programa A

```
numero ← 5

MENTRE numero < 5 FER
    MOSTRAR numero
    numero ← numero + 1
FI_MENTRE
```

Programa B

```
numero ← 5

MENTRE numero <= 5 FER
    MOSTRAR numero
    numero ← numero + 1
FI_MENTRE
```

Programa C

```
numero ← 5

MENTRE numero >= 5 FER
    MOSTRAR numero
    numero ← numero + 1
FI_MENTRE
```

Completa la taula:

| Programa | Què mostra? | Quantes vegades es repetix? | Acaba? |
| -------- | ----------- | --------------------------- | ------ |
| A        |             |                             |        |
| B        |             |                             |        |
| C        |             |                             |        |

Pregunta: explica per què canviar un únic operador de comparació pot modificar completament el funcionament d'un bucle.
