# 2.2.4 Repàs, seguiment i proves de condicionals

Esta pàgina reforça les explicacions i els exercicis anteriors. No incorpora bucles, funcions pròpies ni estructures de dades noves.

## 1. Seguim una condició pas a pas

Considera esta regla: pot entrar una persona major d’edat que siga sòcia, o qualsevol persona VIP.

```python
edat = 17
soci = True
vip = False

if (edat >= 18 and soci) or vip:
    print("Pot entrar")
else:
    print("Accés denegat")
```

Per a raonar, podem descompondre la condició:

| Edat | Soci | VIP | `edat >= 18` | `(edat >= 18 and soci)` | Condició completa | Eixida |
|---:|---|---|---|---|---|---|
| 17 | True | False | False | False | False | Accés denegat |
| 18 | True | False | True | True | True | Pot entrar |
| 18 | False | False | True | False | False | Accés denegat |
| 17 | False | True | False | False | True | Pot entrar |

La taula permet estudiar els valors lògics. L’avaluació real pot ometre alguna part per curtcircuit: si `edat >= 18` és falsa, l’`and` no necessita consultar `soci`; si la primera part de l’`or` és certa, no necessita consultar `vip`.

**Activitat:** afig dos casos diferents a la taula i justifica el resultat abans d’executar-los.

## 2. Taules de veritat bàsiques

Quan A i B són booleans:

| A | B | `A and B` | `A or B` |
|---|---|---|---|
| False | False | False | False |
| False | True | False | True |
| True | False | False | True |
| True | True | True | True |

| A | `not A` |
|---|---|
| False | True |
| True | False |

## 3. Seguim una cadena d’alternatives

```python
nota = 6.5

if nota >= 9:
    print("Excel·lent")
elif nota >= 5:
    print("Aprovat")
else:
    print("Suspés")

print("Final")
```

| Pas | Comprovació o acció | Resultat |
|---|---|---|
| 1 | `nota >= 9` | False: no entra en el primer bloc |
| 2 | `nota >= 5` | True: mostra «Aprovat» |
| 3 | Alternativa `else` | S’omet; no té una condició pròpia |
| 4 | Instrucció posterior a la cadena | Mostra «Final» |

Eixida:

```text
Aprovat
Final
```

**Activitat:** repetix el seguiment amb notes 4.99 i 9. Indica quines condicions no s’arriben a avaluar.

## 4. Predicció d’eixides

Primer escriu la resposta sense executar el codi. Després comprova-la.

### Predicció 1: `if` independents

```python
numero = 12

if numero > 0:
    print("Positiu")
if numero % 2 == 0:
    print("Parell")
print("Final")
```

Quants missatges apareixen? Per què les dues decisions poden aplicar-se a la vegada?

### Predicció 2: ordre dels llindars

```python
nota = 9

if nota >= 5:
    print("Aprovat")
elif nota >= 9:
    print("Excel·lent")
```

Quin missatge apareix? Què has de canviar si vols que una nota de 9 es classifique com a excel·lent?

### Predicció 3: comprovació interna

```python
edat = 16
soci = True

if edat >= 18:
    if soci:
        print("Descompte")
    else:
        print("Tarifa normal")
else:
    print("Accés denegat")
```

S’arriba a comprovar `soci`? A quin `if` correspon cada `else`?

### Predicció 4: curtcircuit

```python
divisor = 0

if divisor != 0 and 20 / divisor >= 4:
    print("Quocient suficient")
print("Final")
```

Hi ha una divisió per zero? Explica per què importa l’ordre de les dues parts.

## 5. Depuració: localitza l’error i justifica la correcció

Els fragments d’este apartat són **incorrectes expressament**. Alguns no es poden executar i altres s’executen però no fan allò que es demana.

### Error 1: assignació dins del `if`

```python
edat = 18

if edat = 18:
    print("Té 18 anys")
```

Identifica l’operador que hauria d’utilitzar-se per a comprovar la igualtat.

### Error 2: text que es confon amb un booleà

```python
soci = bool(input("Eres soci? (si/no): "))

if soci:
    print("Descompte")
else:
    print("Tarifa normal")
```

Per què respondre `no` també dona descompte? Reescriu la lectura amb una comparació. Pressuposa respostes `si` o `no`.

### Error 3: interval impossible

```python
edat = 15

if edat >= 12 and edat <= 10:
    print("Adolescent")
```

L’objectiu és reconéixer les edats entre 12 i 17, incloses. Corregix els límits i prepara proves amb 11, 12, 17 i 18.

### Error 4: divisió abans de la comprovació

```python
divisor = 0

if 10 / divisor > 2 and divisor != 0:
    print("Quocient major que 2")
```

La comprovació arriba a temps? Reordena les parts perquè no es calcule la divisió quan el divisor és zero.

### Error 5: dos descomptes compatibles tractats com a alternatives

```python
total = 100
nocturna = True
bo_social = True

if nocturna:
    total = total * 0.95
elif bo_social:
    total = total * 0.75

print(f"{total:.2f}")
```

Les regles indiquen que s’han d’aplicar els dos descomptes, un després de l’altre. Quina estructura has d’utilitzar? El resultat correcte per a estes dades és `71.25`, no `95.00` ni `70.00`.

## 6. Com triar casos de prova

Una sola execució amb una dada intermèdia no comprova bé un condicional.

Per a cada llindar, prova un valor inferior, el mateix llindar i un valor superior. Si la dada és decimal, utilitza també decimals pròxims.

| Regla | Proves recomanades |
|---|---|
| Major d’edat des dels 18 | 17, 18, 19 |
| Adolescent entre 12 i 17 inclosos | 11, 12, 17, 18 |
| Aprovat des de 5 i excel·lent des de 9 | 4.99, 5, 8.99, 9 |
| Descompte entre 100 i 200 inclosos | 99.99, 100, 200, 200.01 |
| Temperatura suau si és major de 15 i fins a 25 | 15, 15.5, 25, 25.1 |
| Divisió per zero | Divisor 0 i divisor diferent de 0 |

En decisions amb prioritats, prova perfils que complisquen diverses condicions a la vegada. Per exemple, un menor de 12 anys amb discapacitat en el cas del transport.

En decisions independents, prova les quatre combinacions: cap condició certa, només la primera, només la segona i les dues certes.
