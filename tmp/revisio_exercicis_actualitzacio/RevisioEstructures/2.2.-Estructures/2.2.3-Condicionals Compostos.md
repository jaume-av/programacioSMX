# 3. Condicionals en Python (estructures condicionals)

En el punt anterior hem aprés a executar codi **només quan una condició es compleix**.
Ara anem un pas més enllà: **decidir què fer quan una condició no es compleix** i **gestionar diversos casos possibles**.

Amb les estructures condicionals, un programa **no té un únic camí**, sinó que pot seguir **camins diferents d’execució** segons les condicions.

Dins d’una mateixa estructura `if/else` o `if/elif/else`, Python executa **com a màxim una de les alternatives**. Amb un `else` final sempre hi ha una alternativa aplicable. Això no s’ha de confondre amb diversos `if` independents, que poden executar diversos blocs.

---

## 3.1 El condicional `if ... else`

La instrucció `else` permet indicar **què ha de fer el programa quan la condició del `if` és falsa**.

### Forma general

```python
if condicio:
    instruccions_si_true
else:
    instruccions_si_false
```

Funcionament:

* Python comprova la condició del `if`.
* Si és `True`, executa **només** el bloc del `if`.
* Si és `False`, executa **només** el bloc del `else`.
* **Sempre s’executa un dels dos blocs**, però **mai els dos**.

---

### Exemple

```python
edat = 16

if edat >= 18:
    print("Ets major d'edat")
else:
    print("Ets menor d'edat")
```

**Eixida per pantalla:**

```
Ets menor d'edat
```

**En el codi anterior:**

* Python comprova la condició `edat >= 18`.
* El resultat és `False`.
* El bloc del `if` s’ignora completament.
* Python entra directament al `else` i executa el `print`.
* El programa mostra un missatge **en qualsevol cas**.

Si canviem el valor:

```python
edat = 20
```

Eixida:

```
Ets major d'edat
```

---

## 3.2 El condicional `elif` (diverses opcions)

Quan tenim **més de dos casos possibles**, utilitzem `elif` (else if).

### Forma general

```python
if condicio1:
    codi1
elif condicio2:
    codi2
elif condicio3:
    codi3
else:
    codi_final
```

### Funcionament mental del `elif` 

Python:

1. comprova la condició del `if`,
2. si és `False`, passa al primer `elif`,
3. continua comprovant **de dalt a baix**,
4. quan troba **la primera condició que és True**, executa eixe bloc,
5. **ix immediatament de l’estructura**,
6. **no comprova cap altra condició**, encara que també poguera ser True.

* En una estructura `if / elif / else`, **només s’executa un camí possible**.
* Si no hi ha `else` i totes les condicions són falses, no s’executa cap dels blocs de la cadena.
* «Ix de l’estructura» significa que continua després de la cadena de condicionals, no que acabe el programa.

---

### Exemple amb notes

```python
nota = 6.5

if nota >= 9:
    print("Excel·lent")
elif nota >= 5:
    print("Aprovat")
else:
    print("Suspés")
```

**Eixida per pantalla:**

```
Aprovat
```

**Pas a pas:**

* `nota >= 9` és `False` → Python no entra.
* `nota >= 5` és `True` → Python entra en este bloc.
* El missatge “Aprovat” s’imprimeix.
* El `else` no té una condició pròpia: és l’alternativa que només s’executaria si totes les condicions anteriors foren falses. En este cas s’omet.

---

## 3.3 Importància de l’ordre en `elif`

L’ordre de les condicions **canvia completament el comportament del programa**.

### Exemple incorrecte

```python
nota = 9

if nota >= 5:
    print("Aprovat")
elif nota >= 9:
    print("Excel·lent")
```

**Eixida:**

```
Aprovat
```

**Per què passa açò?**

* `nota >= 5` és True.
* Python entra en el primer `if`.
* Entra en eixe bloc i **ix de l’estructura**.
* El `elif` **no s’arriba ni a comprovar**.
* El cas “Excel·lent” queda inaccessible.

### Exemple correcte

```python

nota = 9

if nota >= 9:
    print("Excel·lent")
elif nota >= 5:
    print("Aprovat")
```

* **En esta classificació amb llindars solapats, les condicions més restrictives han d’anar abans**: primer `nota >= 9` i després `nota >= 5`.
* En altres problemes, l’ordre ha de seguir les prioritats de l’enunciat. No és una regla universal d’ordenar totes les condicions de més a menys restrictiva.

---

## 3.4  `if` anidats (condicions dins de condicions)

Un `if` pot estar **dins del bloc d’un altre `if`**.
Això s’anomena **condicional anidat**.

S’utilitza quan:

* una decisió **només té sentit si una altra ja s’ha complert**,
* volem comprovar una segona condició **només en un cas concret**.

---

### Exemple

```python
edat = 20
soci = True

if edat >= 18:
    if soci:
        print("Entrada amb descompte")
    else:
        print("Entrada normal")
else:
    print("Accés denegat")
```

**Eixida per pantalla:**

```
Entrada amb descompte
```

**Explicació detallada:**

1. Python comprova `edat >= 18`.
2. Com que és True, entra dins del primer `if`.
3. Ara comprova la segona condició (`soci`).
4. Com que és True, mostra “Entrada amb descompte”.
5. El `else` exterior no s’executa perquè la primera condició ja era certa.
6. Si `edat` fora menor que 18, **Python no comprovaria mai `soci`**.

>IMPORTANT!! **les condicions internes només s’avaluen si s’entra al bloc exterior**.

---

## 3.5 `elif` o `if` anidat? (comparació)

Moltes vegades, una estructura amb `elif` **pot substituir un `if` anidat**, fent el codi més clar.

### Amb `elif`

```python
if edat < 18:
    print("Menor d'edat")
elif edat < 65:
    print("Adult")
else:
    print("Jubilat")
```

### Amb `if` anidat

```python
if edat < 18:
    print("Menor d'edat")
else:
    if edat < 65:
        print("Adult")
    else:
        print("Jubilat")
```

**Conclusió:**

* Els dos codis fan exactament el mateix.
* `elif` és **més llegible i més fàcil d’entendre**.
* Els `if` anidats s’han d’utilitzar **només quan realment fan falta**.

---

## 3.6 Errors habituals en estructures condicionals

### Oblidar el `else` quan cal

Si volem una resposta per al cas en què cap condició de la cadena es complix, un `else` final permet cobrir-lo. No és obligatori afegir-lo si no cal fer res en eixe cas o si ja s’han cobert explícitament totes les possibilitats.

---

### Errors d’indentació

```python
if edat >= 18:
    print("Major")
else:
print("Menor")
```

Error:

```
IndentationError
```

La indentació incorrecta fa que Python **no sàpiga quin bloc correspon a cada condició**.

---

### Condicions impossibles

```python
edat = 15

if edat < 10 and edat > 20:
    print("Esta línia no s’executarà")
```

Esta condició **mai pot ser True**, perquè una edat no pot complir les dues coses alhora.

---

## 3.7 Diversos `if` independents o una cadena amb `elif`?

No representen la mateixa decisió.

### Dos `if` independents

```python
nota = 9

if nota >= 5:
    print("Aprovat")

if nota >= 9:
    print("Excel·lent")
```

Eixida:

```text
Aprovat
Excel·lent
```

Python comprova els dos `if`. Les dues condicions són certes i s’executen els dos blocs.

### Una cadena d’alternatives

```python
nota = 9

if nota >= 9:
    print("Excel·lent")
elif nota >= 5:
    print("Aprovat")
```

Eixida:

```text
Excel·lent
```

La primera condició ja és certa. Python no avalua l’`elif` i continua després de la cadena.

| Necessitat | Estructura adequada |
|---|---|
| Aplicar diverses accions compatibles | Diversos `if` independents |
| Triar una única categoria | `if/elif/else` |
| Fer una segona decisió només dins d’un cas | `if` anidat |

En el cas de la factura de llum, els descomptes nocturn i social poden aplicar-se tots dos: no els hem de convertir en alternatives excloents amb `elif`.

## 3.8 Validar una entrada sense bucles ni eixides anticipades

Per a no calcular amb una dada incorrecta, podem situar el càlcul dins de l’alternativa vàlida:

```python
resposta = input("Eres soci? (si/no): ")

if resposta != "si" and resposta != "no":
    print("Resposta no vàlida")
else:
    soci = resposta == "si"
    if soci:
        print("Entrada amb descompte")
    else:
        print("Entrada normal")

print("Final")
```

Si s’introduïx `potser`, només apareixen l’avís i el missatge final. El programa no tracta eixe text com un «no» vàlid. Encara no tornem a preguntar: això requerirà un bucle.

El mateix patró permet interpretar «mostra un avís i no calcules res més» en els casos pràctics. No necessitem `exit()`, `quit()` ni funcions pròpies.
