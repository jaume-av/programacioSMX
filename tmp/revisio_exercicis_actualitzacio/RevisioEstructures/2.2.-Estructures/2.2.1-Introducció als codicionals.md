# 1 Introducció a les condicions en Python

En Python, una **condició** és una expressió que el programa pot avaluar com:

* `True`
* `False`

És a dir, una condició **no executa accions**, només **retorna un valor booleà**.

---

## Condicions amb comparacions

Les comparacions generen valors booleans:

```python
5 > 3          # True
10 == 2 * 5    # True
4 != 4         # False
```

Exemple amb variables:

```python
edat = 17
print(edat >= 18)
```

Eixida:

```
False
```

La comparació `edat >= 18` **no decideix res encara**, només diu si és certa o no.

---

## Expressions booleanes

Podem combinar comparacions amb operadors lògics (`and`, `or`, `not`):

```python
edat = 15
adolescent = edat >= 12 and edat <= 17
print(adolescent)
```

Eixida:

```
True
```

En estos exemples combinem comparacions i variables booleanes, de manera que el resultat és `True` o `False`.

Mantindrem este ús durant la unitat. En Python, `and` i `or` també poden operar amb altres tipus i retornar un dels operands; no hem de generalitzar que qualsevol expressió amb estos operadors retorna sempre un `bool`.

---

## Guardar una condició en una variable

Una condició es pot guardar en una variable booleana:

```python
edat = 20
es_major_edat = edat >= 18

print(es_major_edat)
```

Eixida:

```
True
```

Això és molt habitual en programes reals i fa el codi més clar.

---

## Llegir respostes «si/no» i obtindre booleans

`input()` retorna sempre text. Per tant, escriure `False` per teclat no crea automàticament el valor booleà `False`.

En els exercicis d’esta unitat, quan es demane una resposta afirmativa o negativa, escriu **`si` o `no` en minúscula, sense accent**. Convertim la resposta mitjançant una comparació:

```python
resposta = input("Eres soci? (si/no): ")
soci = resposta == "si"

print(soci)
```

| Text introduït | Comparació | Valor de `soci` |
|---|---|---|
| `si` | `"si" == "si"` | `True` |
| `no` | `"no" == "si"` | `False` |

Podem repetir el mateix procediment per a `vip`, `repetidor`, `autoritzacio` o altres estats. No cal estudiar funcions pròpies ni utilitzar `eval()`.

**No utilitzes `bool(input(...))` per a interpretar «si/no» o «True/False».** Una cadena no buida es considera certa: tant `bool("True")` com `bool("False")` donen `True`.

En els exercicis bàsics pressuposem que s’introduïx una de les dues respostes indicades. Una vegada estudiat `if/else`, podrem comprovar explícitament si la resposta és vàlida. No considerem qualsevol altre text com una resposta negativa correcta.

---

## Assignar (`=`) no és comparar (`==`)

És molt important no confondre:

```python
x = 5      # assignació
x == 5     # comparació
```

* `=` guarda un valor
* `==` comprova si dos valors són iguals

Una comparació **no modifica** la variable, només retorna `True` o `False`.

---

## El flux del programa fins ara

Fins ara, els nostres programes:

* s’executen **de dalt a baix**
* totes les línies s’executen **sempre**

Exemple:

```python
print("Inici")
print("Càlcul")
print("Final")
```

Sempre es mostren les tres línies.

---

## Blocs de codi i indentació

Python utilitza la **indentació** per definir blocs de codi.

Encara que no hem vist `if`, ja és important saber que:

* la indentació **no és decorativa**
* indica quines línies formen part d’un mateix bloc

Això serà clau en els condicionals.

En els exemples utilitzarem **quatre espais per cada nivell d’indentació**. Mantín el mateix criteri en tots els blocs i evita mesclar tabulacions amb espais.

---

Fins ara hem aprés a:

* calcular valors
* comparar dades
* obtindre `True` o `False`

 **El següent pas serà executar codi només quan una condició siga True.**

Açò és exactament el que fan els condicionals.
