# 2. Condicionals en Python (simples)

Els condicionals permeten que un programa **prenga decisions**.
A diferència dels programes lineals, en què totes les instruccions s’executen sempre, amb els condicionals podem fer que **algunes línies només s’executen quan es compleix una condició**.

---

## 2.1 Condicions i funcionament bàsic del `if`

Una **condició** és una expressió que Python pot avaluar com a:

* `True`
* `False`

Les condicions **no executen codi**, només indiquen si una situació és certa o falsa.
Per exemple, una comparació com `edat >= 18` només respon a la pregunta: *és cert o no?*

```python
edat = 17
print(edat >= 18)
```

Eixida:

```
False
```

Ací Python comprova la condició i mostra el resultat, però **no pren cap decisió**.

Per a prendre decisions utilitzem la instrucció `if`.

```python
if condicio:
    instruccions
```

El codi indentat sota el `if` **només s’executa si la condició és True**.
Si la condició és False, Python **ignora eixe bloc** i continua amb el programa.

```python
edat = 16

if edat >= 18:
    print("Ets major d'edat")
```

Eixida:

No es mostra res: la condició és falsa i l’únic `print()` està dins del `if`. Esta frase és una explicació, no una eixida del programa.

Com que la condició és falsa, el `print` no s’executa, però el programa **no dona cap error**.

Si canviem el valor:

```python
edat = 20

if edat >= 18:
    print("Ets major d'edat")
```

Eixida:

```
Ets major d'edat
```

---

## 2.2 Flux del programa i importància de la indentació

Un `if` **no interromp l’execució del programa**.
Simplement decidix si entra o no en un bloc de codi.

```python
edat = 15

print("Inici")

if edat >= 18:
    print("Ets major d'edat")

print("Final")
```

Eixida:

```
Inici
Final
```

Encara que la condició siga falsa, el programa continua executant les instruccions següents.

Perquè Python sàpiga quines línies formen part del `if`, utilitza la **indentació**.
La indentació **defineix el bloc**, i per tant és obligatòria.

```python
if edat >= 18:
    print("Accés permés")
    print("Benvingut")
```

Si la condició és True, s’executen **totes dues línies**, perquè estan dins del mateix bloc.

Si no indentem correctament:

```python
if edat >= 18:
print("Accés permés")
```

Python mostra l’error:

```
IndentationError: expected an indented block
```

Açò indica que després d’un `if` **sempre ha d’haver-hi un bloc indentat**.

## 2.3 Condicions simples i condicions compostes en un `if`

Fins ara hem vist condicions simples, és a dir, una sola comparació:

```python
nota = 7

if nota >= 5:
    print("Has aprovat")
```

Eixida:

```
Has aprovat
```

Si la condició no es compleix, no passa res: el bloc no s’executa.

També podem utilitzar **condicions compostes**, combinant diverses comprovacions amb operadors lògics, però **continuem tenint un únic `if`** i **cap alternativa encara**.

### AND

Amb l’operador `and`, **totes les condicions han de ser certes**:

```python
edat = 17
autoritzacio = True

if edat >= 16 and autoritzacio:
    print("Pots entrar")
```

Eixida:

```
Pots entrar
```

### OR

Amb l’operador `or`, **n’hi ha prou que una siga certa**:

```python
vip = False
soci = True

if vip or soci:
    print("Accés especial")
```

Eixida:

```
Accés especial
```

### NOT

Amb l’operador `not`, invertim el valor d’una condició:

```python
repetidor = False

if not repetidor:
    print("Pot passar de curs")
```

Eixida:

```
Pot passar de curs
```

>`not` canvia True per False i False per True.

> **Nota:** Per què passa de curs si `repetidor` és `False`? Perquè `not repetidor` val `True`, que és el valor que avalua el `if`.

### Parèntesis

Quan la condició és més llarga, podem utilitzar parèntesis per millorar la claredat:

```python
edat = 17
vip = True
soci = False

if (edat >= 18 and soci) or vip:
    print("Pot entrar")
```

Eixida:

```
Pot entrar
```

Tot i que la condició és més complexa, el funcionament és sempre el mateix:

* Python avalua la condició,
* si el resultat és `True`, executa el bloc,
* si és `False`, el salta.

## 2.4 Errors habituals en condicionals simples

Un dels errors més freqüents és confondre **assignació** i **comparació**.

```python
edat = 18      # assignació
edat == 18     # comparació
```

Després d’un `if` escrivim **una condició**. Pot ser una comparació, com `edat >= 18`, una variable booleana, com `soci`, o una combinació, com `edat >= 18 and soci`.

No és obligatori escriure una comparació explícita si ja tenim un booleà. El que no podem fer és confondre l’assignació `=` amb la comparació `==`, com en este exemple incorrecte:

```python
if edat = 18:
```

Produeix l’error:

```
SyntaxError: invalid syntax
```

---


## 2.5 Curtcircuit: no sempre s’avaluen totes les parts

Python avalua les condicions d’esquerra a dreta i pot deixar d’avaluar-les quan ja coneix el resultat:

- En `A and B`, si `A` és falsa, no s’avalua `B`.
- En `A or B`, si `A` és certa, no s’avalua `B`.

Açò s’anomena **curtcircuit**. És útil quan una comprovació protegix una operació que podria fallar:

```python
divisor = 0

if divisor != 0 and 10 / divisor > 2:
    print("El quocient és major que 2")

print("Final")
```

Eixida:

```text
Final
```

`divisor != 0` és falsa, així que Python no calcula `10 / divisor`. No hi ha divisió per zero. No invertisques l’ordre de les dues parts: la comprovació de seguretat ha d’anar primer.

## 2.6 Condició composta dins d’un condicional simple

```python
edat = 17
autoritzacio = True

if edat >= 16 and autoritzacio:
    print("Pots entrar")
```

Hi ha dues comprovacions combinades, però només un bloc condicional. Per tant, la **condició és composta** i el **condicional és simple**. Si la condició és falsa, no hi ha cap bloc alternatiu.
