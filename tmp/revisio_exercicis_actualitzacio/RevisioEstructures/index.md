# Revisió de les estructures condicionals

Esta és una còpia de revisió independent. El material original no s’ha modificat.

Accedix a **2. Python → 2.2 Estructura** des del menú lateral.

Per a substituir el material, copia únicament el contingut de `2.2.-Estructures` sobre la carpeta equivalent del curs. Les instruccions detallades i el registre de canvis estan en `README.md` i `REGISTRE_REVISIO.md`.
